# hideSkippedTests

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--hideSkippedTests`

Hide log output for skipped test cases. The summary counts at the bottom still include skipped tests.

When running multiple test files with the `default` reporter, individual non-failing cases (including skipped ones) are already omitted from the output. This option takes effect when running a single test file or using the [verbose reporter](/guide/basic/reporters#verbose-reporter).

## Example

With the [verbose reporter](/guide/basic/reporters#verbose-reporter) (or a single-file run), skipped cases are shown by default:

```bash
 ✓ test/index.test.ts (2) 1ms
  ✓ Index > should add two numbers correctly (0ms)
  - Index > should test source code correctly

 Test Files 1 passed
      Tests 1 passed | 1 skipped (2)
   Duration 93ms (build 50ms, tests 43ms)
```

With `hideSkippedTests: true`, skipped test cases are omitted from the output:

```bash
 ✓ test/index.test.ts (2) 1ms
  ✓ Index > should add two numbers correctly (0ms)

 Test Files 1 passed
      Tests 1 passed | 1 skipped (2)
   Duration 93ms (build 50ms, tests 43ms)
```
