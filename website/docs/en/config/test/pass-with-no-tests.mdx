# passWithNoTests

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--passWithNoTests`

Allow Rstest to pass when no test files or test cases are found.

By default, Rstest exits with code `1` when no test files match, and fails any test file or suite that contains no tests. Set `passWithNoTests: true` to exit with code `0` and mark empty files and suites as passed.

When running with `--changed`, `passWithNoTests` defaults to `true` unless explicitly set to `false`.
