# resolveSnapshotPath

- **Type:** `(testPath: string, snapExtension: string) => string`
- **Default:** `undefined`

Customize where Rstest stores snapshot files.

By default, Rstest saves snapshot files in a `__snapshots__` directory next to each test file. Return a custom path from `resolveSnapshotPath` to change this location.

For example, store snapshots beside test files instead of inside `__snapshots__`:

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  resolveSnapshotPath: (testPath, snapshotExtension) =>
    testPath + snapshotExtension,
});
```
