# name

- **Type:** `string`
- **Default:** `'rstest'` (single project), or inferred from `package.json` / directory name in [projects](/config/test/projects)

Set the name of the test project. Used in reporter output and to select projects with [--project](/guide/basic/test-filter#filter-by-project-name).

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  name: 'node',
});
```

Project names must be unique across all entries declared in [projects](/config/test/projects); Rstest errors at startup if two projects share a name.

When `name` is omitted on a project inside `projects`, Rstest uses the `name` field from that project's `package.json`, falling back to its directory name. For a standalone run without `projects`, `name` defaults to `'rstest'`.
