# bail

- **Type:** `number`
- **Default:** `0`
- **CLI:** `--bail [number]` (default: `1`)

Stop the test run after the specified number of test failures.

Set this to `0` (the default) to run all tests regardless of failures, or `1` to stop after the first test failure.
