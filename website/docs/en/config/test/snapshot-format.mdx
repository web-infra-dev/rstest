# snapshotFormat

- **Type:** `Omit<PrettyFormatOptions, 'plugins' | 'compareKeys'>`
- **Default:** `{ printShadowRoot: false }`

Customize snapshot serialization using options from [pretty-format](https://www.npmjs.com/package/pretty-format). `plugins` and `compareKeys` are omitted because snapshot format options must be serializable across worker boundaries.

Rstest omits shadow roots from snapshots by default. Set `printShadowRoot` to `true` to include them.

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  snapshotFormat: {
    printBasicPrototype: true,
  },
});
```
