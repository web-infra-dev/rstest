# update

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `-u`, `--update`

Update all changed snapshots, write missing snapshots, and delete obsolete snapshots during the test run. In Browser Mode, this also replaces mismatched screenshot references for [`toMatchScreenshot`](/api/runtime-api/browser-mode/assertion#toMatchScreenshot).

By default (`false`), existing changed snapshots fail and obsolete snapshots are kept. Missing snapshots (including missing screenshot references) are still created automatically during local runs, whereas in CI environments missing snapshots fail unless `update` is enabled.

In watch mode, you can also press `u` to trigger a snapshot update run.
