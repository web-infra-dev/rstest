# resetMocks

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--resetMocks`

Clear all mock state and reset each mock's implementation to its original implementation before every test.

When `resetMocks` is enabled, Rstest calls [rs.resetAllMocks()](/api/runtime-api/rstest/mock-functions#rsresetallmocks) before each test.
