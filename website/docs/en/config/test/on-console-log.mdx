# onConsoleLog

- **Type:** `(content: string, type: 'stdout' | 'stderr') => boolean | void`
- **Default:** `undefined`

Intercept `console` output emitted during tests before Rstest prints it. Return `false` to suppress the log; return `true` or `undefined` to print it as usual.

This is a global option set in the root config and cannot be overridden per project in [`projects`](/config/test/projects).

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  onConsoleLog: (content, type) => {
    if (type === 'stderr' && content.includes('deprecated')) {
      return false;
    }
  },
});
```

To hide all test console output or only show logs from failed tests without writing a custom filter, use [`silent`](/config/test/silent).

:::note
When [`disableConsoleIntercept`](/config/test/disable-console-intercept) is `true`, `onConsoleLog` has no effect. Logs discarded by `silent` are also not passed to `onConsoleLog`.
:::
