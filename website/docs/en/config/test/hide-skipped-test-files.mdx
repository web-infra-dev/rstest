# hideSkippedTestFiles

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--hideSkippedTestFiles`

Hide log output for skipped test files. Useful when filters or file-level skips leave many skipped files in the output.

The summary counts at the bottom still include skipped files.

import { Tab, Tabs } from '@theme';

<Tabs defaultValue='rstest.config.ts'>

import { defineConfig } from '@rstest/core';

export default defineConfig({
  hideSkippedTestFiles: true,
});

## Example

By default, Rstest logs every test file, including skipped ones:

```bash
 ✓ test/index.test.ts (1)
 - test/all-skipped.test.ts (2)

 Test Files 1 passed | 1 skipped
      Tests 1 passed | 2 skipped (3)
   Duration 93ms (build 50ms, tests 43ms)
```

With `hideSkippedTestFiles: true`, skipped files are omitted from the file list:

```bash
 ✓ test/index.test.ts (1)

 Test Files 1 passed | 1 skipped
      Tests 1 passed | 2 skipped (3)
   Duration 93ms (build 50ms, tests 43ms)
```
