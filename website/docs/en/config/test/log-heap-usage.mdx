# logHeapUsage

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--logHeapUsage`

Print V8 `heapUsed` memory usage after each test file and displayed test case to help spot memory leaks.

Applies to Node.js tests only; ignored with a warning in [Browser Mode](/config/test/browser).

## Example

With `logHeapUsage: true`, each test line prints its heap usage:

```bash
 ✓ test/index.test.ts (2) 11 MB heap used
 ✓ test/index1.test.ts (2) 11 MB heap used

 Test Files 2 passed
      Tests 2 passed | 2 skipped (4)
   Duration 233ms (build 175ms, tests 58ms)
```
