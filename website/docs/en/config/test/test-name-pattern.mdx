# testNamePattern

- **Type:** `string | RegExp`
- **Default:** `undefined`
- **CLI:** `-t=<value>`, `--testNamePattern=<value>`

Filter which tests run by matching their full name against a `RegExp` or regex pattern string (compiled with `new RegExp()`).

The full name joins enclosing `describe` suite names and the test name with spaces (or `' > '` when the pattern contains `>`).
