# unstubEnvs

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--unstubEnvs`

Automatically calls [`rs.unstubAllEnvs()`](/api/runtime-api/rstest/utilities#rsunstuballenvs) before every test, restoring all `process.env` and `import.meta.env` values changed with [`rs.stubEnv()`](/api/runtime-api/rstest/utilities#rsstubenv) to their original values.
