# playwright

<ApiMeta addedVersion="0.12.0" />

- **Type:**

```ts
playwright?: Record<string, unknown>;
```

Set default options for the `playwright` fixture provided by [@rstest/playwright](/guide/advanced/playwright) in the current project.

Use `satisfies PlaywrightOptions` to get the concrete Playwright type from the integration package:

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';
import type { PlaywrightOptions } from '@rstest/playwright';

export default defineConfig({
  playwright: {
    launchOptions: {
      channel: 'chrome',
    },
    contextOptions: {
      viewport: { width: 1440, height: 900 },
    },
    trace: 'on-first-retry',
  } satisfies PlaywrightOptions,
});
```

Only JSON- or structured-clone-serializable values can be passed through the worker transport. Functions such as `launchOptions.logger`, class instances, and values that depend on the current test or retry context are not supported; use `test.extend` for these cases.

## Override with test.extend

Use `test.extend` when one test or a group of tests needs different Playwright options:

```ts title="tests/mobile.test.ts"
import { expect, test as base } from '@rstest/playwright';
import type { PlaywrightOptions } from '@rstest/playwright';

const test = base.extend({
  playwright: {
    browserName: 'chromium',
    contextOptions: {
      viewport: { width: 390, height: 844 },
    },
  } satisfies PlaywrightOptions,
});

test('uses the overridden viewport', async ({ page }) => {
  expect(page.viewportSize()).toEqual({ width: 390, height: 844 });
});
```

The override replaces the project-level `playwright` value instead of merging with it. Include every project option that the test should keep.

The options are available in Node workers through `rs.getConfig().playwright`. They must be serializable across the worker transport. Use `test.extend` for functions, class instances, dynamic retry-dependent values, or test-specific overrides.

When a test overrides the `playwright` fixture with `test.extend`, the fixture override takes precedence over this project configuration.
