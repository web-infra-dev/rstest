# reporters

- **Type:**

```ts
type ReporterItem =
  | Reporter
  | BuiltInReporterNames
  | (string & {})
  | ReporterWithOptions
  | [string]
  | [string, Record<string, unknown>];

type Reporters =
  Reporter | BuiltInReporterNames | (string & {}) | ReporterItem[];
```

- **Default:**

```ts
process.env.GITHUB_ACTIONS === 'true'
  ? ['default', 'github-actions']
  : ['default'];
```

- **CLI:** `--reporters=<name> --reporters=<name1>` (`--reporter` is also accepted as an alias)

Configure which reporters to use for test result output.

Built-in reporter names: `default`, `dot`, `verbose`, `md`, `github-actions`, `junit`, `json`, and `blob`.

This is a global option set in the root config and cannot be overridden per project in [`projects`](/config/test/projects).

:::info AI agent environments
When no `reporters` are configured (neither in config nor via `--reporters`), Rstest defaults to `['md']` in AI agent environments and writes agent-friendly Markdown to stdout.
:::

## Usage

### Basic example

import { Tab, Tabs } from '@theme';

<Tabs defaultValue='rstest.config.ts'>

  </Tab>

### Multiple reporters

Pass an array to combine console output with file reports for CI/CD pipelines:

<Tabs defaultValue='rstest.config.ts'>
  <Tab label="CLI">

```bash
npx rstest --reporters=default --reporters=junit
```

  </Tab>
  <Tab label="rstest.config.ts">

```ts
import { defineConfig } from '@rstest/core';

export default defineConfig({
  reporters: ['default', 'junit'],
});
```

  </Tab>
</Tabs>

### Configuring reporters with options

Pass `[reporterName, options]` inside the `reporters` array to configure a reporter. See the [Reporters guide](/guide/basic/reporters) for each built-in reporter's available options:

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  reporters: [
    ['default', { summary: false }],
    ['github-actions', { summary: { maxCharsPerField: 1000 } }],
    ['junit', { outputPath: './test-results.xml' }],
  ],
});
```

### Custom reporters

Pass a module specifier (or `[specifier, options]`) whose default export is a class implementing `Reporter`, or pass an already constructed `Reporter` object directly (reporter classes cannot be passed directly). See the [Reporter API reference](/api/javascript-api/reporter) for the `Reporter` interface, constructor signature, and TypeScript support.
