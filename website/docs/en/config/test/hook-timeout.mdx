# hookTimeout

- **Type:** `number`
- **Default:** `10_000`
- **CLI:** `--hookTimeout=10000`

Default timeout of lifecycle [hooks](/api/runtime-api/test-api/hooks) (`beforeAll`, `afterAll`, `beforeEach`, `afterEach`, `onTestFinished`, and `onTestFailed`) in milliseconds. Set to `0` to disable the timeout.

Rstest resolves the hook timeout in the following priority order:

1. The `timeout` argument passed to an individual [hook](/api/runtime-api/test-api/hooks)
2. File-level timeout set via [`rs.setConfig({ hookTimeout })`](/api/runtime-api/rstest/utilities#rssetconfig)
3. `--hookTimeout` CLI option
4. `hookTimeout` in the configuration file
5. Default value of `10_000` milliseconds
