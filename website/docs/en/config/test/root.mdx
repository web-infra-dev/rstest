# root

- **Type:** `string`
- **Default:** [process.cwd()](https://nodejs.org/api/process.html#processcwd)
- **CLI:** `-r=<path>`, `--root=<path>`

Project root directory, specified as an absolute path or relative to `process.cwd()`. It sets the base directory for discovering test files and resolving `<rootDir>`.

When passed via CLI (`-r` or `--root`), it also sets the starting directory for loading configuration files.

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  setupFiles: ['<rootDir>/setup.js'],
  include: ['<rootDir>/**/*.{test,spec}.?(c|m)[jt]s?(x)'],
  root: './my-project',
});
```
