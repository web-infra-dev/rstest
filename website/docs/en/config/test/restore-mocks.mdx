# restoreMocks

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--restoreMocks`

Restore object methods replaced by `rs.spyOn()` before every test. Mock call history and implementations remain unchanged, and standalone mocks created with `rs.fn()` are not affected.

When `restoreMocks` enabled, rstest will call [.restoreAllMocks()](/api/runtime-api/rstest/mock-functions#rsrestoreallmocks) before each test.
