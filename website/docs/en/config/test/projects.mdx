# projects

- **Type:**

```ts
import type { ProjectConfig } from '@rstest/core';

type InlineProjectConfig = ProjectConfig & { name: string };

type GlobProject = {
  glob: string;
  extends: NonNullable<ProjectConfig['extends']>;
};

type Projects = (string | InlineProjectConfig | GlobProject)[];
```

- **Default:** `undefined` (runs the root directory as a single project)

Run multiple test projects in a single Rstest process and combine all results in the output. Each entry in the array can be a directory path, config file path, glob pattern, or inline project configuration object.

```ts title="rstest.config.ts"
import { defineConfig, defineInlineProject } from '@rstest/core';

export default defineConfig({
  projects: [
    // Monorepo: each package directory is a project
    'packages/*',

    // Inline project config
    defineInlineProject({
      name: 'react',
      include: ['tests/react/**/*.{test,spec}.{js,cjs,mjs,ts,tsx}'],
      testEnvironment: 'jsdom',
    }),
  ],
});
```

To give discovered projects shared defaults, use a directory glob with `extends`:

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  projects: [
    {
      glob: 'packages/*',
      extends: { globals: true, setupFiles: ['./setup.ts'] },
    },
  ],
});
```

Each matched directory is a project, including directories without a config file. Relative setup paths resolve from that project. Its config and inherited settings override the glob defaults. Plain objects merge recursively and local arrays replace default arrays. When multiple glob entries match the same directory, the first provides its defaults.

Use `defineInlineProject()` (requires [`name`](/config/test/name)) for named inline items in a `projects` array, and `defineProject()` (which can infer `name`) for top-level exports of project config files.

To run only specific projects from the command line, pass `--project <name>` (supports wildcards). See [Test projects](/guide/basic/projects) for directory/glob entries, sharing configs, global options, and nested projects.
