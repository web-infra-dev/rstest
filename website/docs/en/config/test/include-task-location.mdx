# includeTaskLocation

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--includeTaskLocation`

Include `location` (`{ line, column }`) on collected test cases and suites in reporter payloads (`TestCaseInfo`, `TestSuiteInfo`) and `list` output.

Enabling this option adds stack-capture overhead during test collection and may slightly slow down runs.

## Using with the list command

Pass `--printLocation` to `rstest list` to enable `includeTaskLocation` automatically and print `file:line:column` beside each test:

```bash
npx rstest list --printLocation
```

## Example output

With `includeTaskLocation: true`, reporter `TestCaseInfo` and `TestSuiteInfo` objects include a `location` field:

```json
{
  "testId": "test-1",
  "name": "should calculate correct sum",
  "testPath": "/path/to/test.spec.ts",
  "location": {
    "line": 15,
    "column": 3
  }
}
```
