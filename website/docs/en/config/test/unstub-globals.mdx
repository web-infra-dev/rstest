# unstubGlobals

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--unstubGlobals`

Automatically calls [`rs.unstubAllGlobals()`](/api/runtime-api/rstest/utilities#rsunstuballglobals) before every test, restoring all `globalThis` properties changed with [`rs.stubGlobal()`](/api/runtime-api/rstest/utilities#rsstubglobal) to their original descriptors (or deleting properties that did not exist).
