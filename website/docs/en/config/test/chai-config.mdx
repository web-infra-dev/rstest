description: Customize Chai options, such as diff display and value truncation.
---

# chaiConfig

- **Type:**

```ts
type ChaiConfig = {
  /**
   * @default true
   */
  showDiff?: boolean;
  /**
   * @default 40
   */
  truncateThreshold?: number;
};
```

- **Default:** `undefined`

Customize the [Chai config](https://github.com/chaijs/chai/blob/5.x.x/lib/chai/config.js).

### truncateThreshold

- **Type:** `number`
- **Default:** `40`

Maximum number of characters to display for objects and arrays in assertion failure messages. Values exceeding this threshold are truncated.

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  chaiConfig: {
    truncateThreshold: 100, // Show up to 100 characters
  },
});
```

With the default `40`, long arrays or objects are truncated:

```text
AssertionError: expected [ 1, 2, [ 3, [ 4 ], ... ] ] to strictly equal
[ 1, 2, [ 3 ] ]
```

With a higher threshold, the full structure is printed:

```text
AssertionError: expected [ 1, 2, [ 3, [ 4 ], { a: 1, length: 1 } ] ] to strictly equal
[ 1, 2, [ 3 ] ]
```

### showDiff

- **Type:** `boolean`
- **Default:** `true`

Show a diff of expected vs. actual values in assertion failures.

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  chaiConfig: {
    showDiff: false, // Hide diff output
  },
});
```

By default, Rstest prints a diff on assertion failures:

```text
AssertionError: expected { a: 1, b: 2 } to deeply equal { a: 1, b: 3 }
  + expected
  - actual

  {
    "a": 1
+   "b": 3
-   "b": 2
  }
```

With `showDiff: false`, Rstest prints only the plain assertion message:

```text
AssertionError: expected { a: 1, b: 2 } to deeply equal { a: 1, b: 3 }
```
