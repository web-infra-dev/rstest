# printConsoleTrace

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--printConsoleTrace`

Print the stack trace where `console` methods (such as `console.log` or `console.warn`) are called during tests, helping locate where each log originates.

import { Tab, Tabs } from '@theme';

<Tabs defaultValue='rstest.config.ts'>
  <Tab label="CLI">
  ```bash
  npx rstest --printConsoleTrace
  ```
  </Tab>
  <Tab label="rstest.config.ts">
```ts
import { defineConfig } from '@rstest/core';

export default defineConfig({
  printConsoleTrace: true,
});
```
  </Tab>
</Tabs>

:::note
When [`disableConsoleIntercept`](/config/test/disable-console-intercept) is `true`, `printConsoleTrace` has no effect.
:::
