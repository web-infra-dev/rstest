# disableConsoleIntercept

- **Type:** `boolean`
- **Default:** `false`
- **CLI:** `--disableConsoleIntercept`

Disable Rstest's console log interception. By default, Rstest intercepts `console` calls to associate logs with their test source.

import { Tab, Tabs } from '@theme';

<Tabs defaultValue='rstest.config.ts'>
  <Tab label="CLI">
  ```bash
  npx rstest --disableConsoleIntercept
  ```
  </Tab>
  <Tab label="rstest.config.ts">
```ts
import { defineConfig } from '@rstest/core';

export default defineConfig({
  disableConsoleIntercept: true,
});
```
  </Tab>
</Tabs>

When `disableConsoleIntercept` is `true`, [onConsoleLog](/config/test/on-console-log) and [printConsoleTrace](/config/test/print-console-trace) do not take effect. If [silent](/config/test/silent) is also enabled, Rstest still keeps an internal interception path so `silent` can control test log output; in Browser Mode, that path still calls the original `console.*` for DevTools.
