# source

Options for input source code.

## source.decorators <RsbuildDocBadge path="/config/source/decorators" text="source.decorators" />

- **Type:** `{ version?: 'legacy' | '2022-03' | '2023-11' }`
- **Default:** `{ version: '2023-11' }`

Configures the decorator syntax version.

If you use TypeScript's [experimentalDecorators](https://www.typescriptlang.org/tsconfig/#experimentalDecorators), set `source.decorators.version` to `'legacy'`.

## source.assetsInclude <RsbuildDocBadge path="/config/source/assets-include" text="source.assetsInclude" />

<ApiMeta addedVersion="0.9.6" />

- **Type:** `Rspack.RuleSetCondition`
- **Default:** `undefined`

Specifies additional file types to treat as static assets, beyond Rsbuild's built-in asset rules (such as `.txt` or `.md`).

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  source: {
    assetsInclude: /\.(txt|md)$/,
  },
});
```

If you reuse an Rsbuild or Rslib config via `@rstest/adapter-rsbuild` or `@rstest/adapter-rslib`, `source.assetsInclude` is inherited automatically.

## source.define <RsbuildDocBadge path="/config/source/define" text="source.define" />

- **Type:** `Rspack.DefinePluginOptions`
- **Default:** `{}` (`import.meta.env` is mapped to `process.env` automatically)

Replaces global identifiers or expressions in your code at compile time, such as injecting build-time environment variables or feature flags.

## source.exclude <RsbuildDocBadge path="/config/source/exclude" text="source.exclude" />

- **Type:** `Rspack.RuleSetCondition[]`
- **Default:** `undefined`

Excludes JavaScript or TypeScript files from [SWC](https://rsbuild.rs/guide/configuration/swc) transformation.

:::note
Files matched by `source.exclude` skip SWC transformation, but referenced files are still bundled into the output.

To keep files out of the bundle completely, use [output.externals](/config/build/output#outputexternals) or Rspack's [IgnorePlugin](https://rspack.rs/plugins/webpack/ignore-plugin).
:::

## source.include <RsbuildDocBadge path="/config/source/include" text="source.include" />

- **Type:** `Rspack.RuleSetCondition[]`
- **Default:** `undefined`

Specifies additional JavaScript or TypeScript files (such as specific `node_modules` packages) to compile with SWC.

## source.transformImport <RsbuildDocBadge path="/config/source/transform-import" text="source.transformImport" />

<ApiMeta addedVersion="0.9.6" />

- **Type:**

```ts
type TransformImport = {
  libraryName: string;
  libraryDirectory?: string;
  customName?: string;
  customStyleName?: string;
  style?: string | boolean;
  styleLibraryDirectory?: string;
  camelToDashComponentName?: boolean;
  transformToDefaultImport?: boolean;
  ignoreEsComponent?: string[];
  ignoreStyleComponent?: string[];
};

type TransformImportFn = (
  imports: TransformImport[],
) => TransformImport[] | void;

type TransformImportConfig =
  TransformImportFn | (TransformImport | TransformImportFn)[];
```

- **Default:** `undefined`

Configures on-demand import transforms (for example, rewriting barrel imports from a component library into direct subpath imports).

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  source: {
    transformImport: [
      {
        libraryName: 'demo-lib',
        libraryDirectory: '.',
        camelToDashComponentName: false,
      },
    ],
  },
});
```

:::caution
`source.transformImport` rewrites the final module request at compile time.

Module-level mocking APIs that reference the original specifier (`rs.mock('pkg')`, `rs.doMock('pkg')`, `rs.importActual('pkg')`, and `rs.requireActual('pkg')`) may no longer match the transformed module request.
:::

## source.tsconfigPath <RsbuildDocBadge path="/config/source/tsconfig-path" text="source.tsconfigPath" />

- **Type:** `string`
- **Default:** `'tsconfig.json'` (auto-detected in each project's root when present)
- **CLI:** `--source.tsconfigPath <path>`

Configures a custom `tsconfig.json` path (relative to the project root or absolute).

When unset, Rstest detects `tsconfig.json` in each project's root and uses its `compilerOptions.paths` mappings for module resolution.

Rstest does not convert other `compilerOptions` into transform settings. Configure build options explicitly when needed—such as [`source.decorators`](#sourcedecorators) for decorator syntax (for example, `version: 'legacy'`) or [`tools.swc`](/config/build/tools#toolsswc) for SWC target settings—or use an [adapter](/guide/advanced/adapters) that maps them for you.
