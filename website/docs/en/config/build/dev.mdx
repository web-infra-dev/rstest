# dev

Options for local development.

## dev.writeToDisk <RsbuildDocBadge path="/config/dev/write-to-disk" text="dev.writeToDisk" />

- **Type:** `boolean | ((filename: string) => boolean)`
- **Default:** `false`
- **CLI:** `--dev.writeToDisk`

Controls whether temporary test build files are written to disk. By default, Rstest keeps build outputs in memory; enable this when debugging generated test bundles.

With `dev.writeToDisk: true`, Node.js workers read the build output directly from disk, which reduces main-process memory usage for large test bundles.

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  dev: {
    writeToDisk: true,
  },
});
```
