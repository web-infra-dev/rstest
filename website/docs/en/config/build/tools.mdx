# tools

Options for low-level tools.

## tools.bundlerChain <RsbuildDocBadge path="/config/tools/bundler-chain" text="tools.bundlerChain" />

- **Type:** `ModifyBundlerChainFn | ModifyBundlerChainFn[]`
- **Default:** `undefined`

Modifies the Rspack configuration via [rspack-chain](https://github.com/rstackjs/rspack-chain), which provides a chainable API for rules, plugins, and optimization settings.

## tools.rspack <RsbuildDocBadge path="/config/tools/rspack" text="tools.rspack" />

- **Type:** `(Rspack.Configuration | ModifyRspackConfigFn) | (Rspack.Configuration | ModifyRspackConfigFn)[]`
- **Default:** `undefined`

Modifies the [Rspack](https://rspack.rs/config/index) configuration directly, either as a configuration object (merged via `rspack-merge`) or a function that mutates or returns a config.

## tools.swc <RsbuildDocBadge path="/config/tools/swc" text="tools.swc" />

- **Type:** `ConfigChain<Rspack.SwcLoaderOptions>`
- **Default:** `undefined`

Configures options passed to Rspack's [builtin:swc-loader](https://rspack.rs/guide/features/builtin-swc-loader).
