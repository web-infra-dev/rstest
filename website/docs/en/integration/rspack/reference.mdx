# Rspack adapter reference

For setup and important caveats, see the [Rspack integration overview](./). This page covers the adapter APIs, configuration mapping, and debug workflow.

## API

### `withRspackConfig(options)`

Returns a configuration function that loads an Rspack config file and converts it to Rstest configuration.

#### `cwd`

- **Type:** `string`
- **Default:** `process.cwd()`

Working directory used to resolve the Rspack config file and relative persistent cache paths.

Use `cwd` when your Rspack config lives in another directory, such as a package in a monorepo:

```ts title="rstest.config.ts"
export default defineConfig({
  extends: withRspackConfig({
    cwd: './packages/my-app',
  }),
});
```

#### `configPath`

- **Type:** `string`
- **Default:** `undefined`

Path to the Rspack config file. Relative paths resolve against `cwd`.

When omitted, the adapter checks `rspack.config.{js,ts,mjs,mts,cjs,cts}` (starting with `.js`) in `cwd`. If no config file is found, or if the specified path does not exist, `withRspackConfig` returns `{}`.

When a config file is loaded, its path is added to [`forceRerunTriggers`](/config/test/force-rerun-triggers) and, for persistent caches, to `performance.buildCache.buildDependencies`.

#### `configName`

- **Type:** `string`
- **Default:** `undefined`

Selects a configuration by its `name` field when your Rspack config exports an array of configs, and sets Rstest's `name` (`configName ?? config.name`). Throws an error if no entry matches. When omitted on an array export, the adapter uses the first entry.

Given an array config:

```ts title="rspack.config.ts"
export default [
  {
    name: 'client',
    target: 'web',
    entry: './src/client.ts',
    // ...
  },
  {
    name: 'server',
    target: 'node',
    entry: './src/server.ts',
    // ...
  },
];
```

Select a single entry with `configName`:

```ts title="rstest.config.ts"
export default defineConfig({
  extends: withRspackConfig({
    configName: 'client',
  }),
});
```

To test multiple targets independently, define separate Rstest `projects`:

```ts title="rstest.config.ts"
export default defineConfig({
  projects: [
    {
      extends: withRspackConfig({ configName: 'server' }),
      include: ['tests/server/**/*.{test,spec}.?(c|m)[jt]s'],
    },
    {
      extends: withRspackConfig({ configName: 'client' }),
      include: ['tests/client/**/*.{test,spec}.?(c|m)[jt]s?(x)'],
    },
  ],
});
```

#### `env`

- **Type:** `Record<string, unknown> | string[]`
- **Default:** `undefined`

Environment values passed to Rspack when loading a function-style config:

```ts title="rspack.config.ts"
export default (env) => {
  console.log(env); // receives the value passed to `env`
  return {/* ... */};
};
```

#### `nodeEnv`

- **Type:** `string`
- **Default:** `undefined`

`NODE_ENV` value used while loading the Rspack config.

#### `modifyRspackConfig`

- **Type:** `(config: RspackOptions) => RspackOptions`
- **Default:** `undefined`

Modifies the selected Rspack config before conversion. The callback must return an `RspackOptions` object:

```ts title="rstest.config.ts"
export default defineConfig({
  extends: withRspackConfig({
    modifyRspackConfig: (rspackConfig) => {
      delete rspackConfig.resolve?.alias;
      return rspackConfig;
    },
  }),
});
```

### `toRstestConfig(options)`

Converts an in-memory `RspackOptions` object directly to Rstest configuration without loading a config file from disk.

```ts title="rstest.config.ts"
import type { RspackOptions } from '@rspack/core';
import { defineConfig } from '@rstest/core';
import { toRstestConfig } from '@rstest/adapter-rspack';

const rspackConfig: RspackOptions = {
  target: 'web',
  resolve: {
    alias: {
      '@': './src',
    },
  },
};

export default defineConfig({
  extends: toRstestConfig({
    rspackConfig,
  }),
});
```

#### `rspackConfig`

- **Type:** `RspackOptions`

The single Rspack configuration object to convert.

#### `configPath`

- **Type:** `string`
- **Default:** `undefined`

Source file path associated with `rspackConfig`. Does not load from disk; adds the normalized path to [`forceRerunTriggers`](/config/test/force-rerun-triggers) and persistent `performance.buildCache.buildDependencies`.

Also accepts `cwd` (used to resolve relative `rspackConfig.context` or as the fallback cache root when `context` is unset), `configName` (overrides `name`), and `modifyRspackConfig`—see [`withRspackConfig`](#withrspackconfigoptions).

## Configuration mapping

The adapter routes each Rspack option based on which layer owns the behavior: equivalent concepts become Rstest config, compatible compiler options are forwarded to Rspack, and build-only or test-incompatible settings stay under Rstest's control.

### Mapped to Rstest options

These options are converted before creating the compiler so Rstest can select the test environment, resolve modules, and configure build caching:

| Rspack option                                                     | Rstest equivalent         | Notes                                                                                                                                        |
| ----------------------------------------------------------------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`                                                            | `name`                    | `configName` takes precedence (`configName ?? config.name`)                                                                                  |
| `resolve.alias`, `extensions`, `conditionNames`, and `mainFields` | `resolve`                 | Shared module-resolution options; `resolve.alias: false` is skipped here and forwarded to `tools.rspack` instead                             |
| `resolve.tsConfig`                                                | `source.tsconfigPath`     | Accepts a string path or `{ configFile }`; full `resolve.tsConfig` is also forwarded to `tools.rspack`                                       |
| `output.module`                                                   | `output.module`           | Output module format                                                                                                                         |
| `target`                                                          | `testEnvironment`         | `'node'` for `'async-node'` or any `node*` target (string or array); `'happy-dom'` for all others or when unset                              |
| `cache`                                                           | `performance.buildCache`  | Maps persistent `storage.directory`, `version`, and `buildDependencies`; `false` or `{ type: 'memory' }` sets `buildCache: false`            |
| `context`                                                         | Persistent cache paths    | Resolves relative `cache.storage.directory`, `cache.storage.location`, and `cache.buildDependencies`                                         |
| `mode`                                                            | Persistent cache identity | Contributes to the default cache name (`<name>-<mode>`, defaulting mode to `'production'`); compiler `mode` is set by Rstest from `NODE_ENV` |

### Merged with Rstest compiler hooks

These options affect the Rspack compilation via `tools.rspack`, while Rstest retains invariants needed by the test runtime:

| Rspack option      | Behavior                                                                                                                                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `module`           | Merges `module` options and appends `rules` after Rstest's base rules                                                                                                                                                          |
| `plugins`          | Appends `plugins` after filtering out `HtmlRspackPlugin`; the adapter also removes Rsbuild's built-in CSS plugins (`rsbuild:css`, `rsbuild:less`, `rsbuild:sass`)                                                              |
| `output`           | Merges `output` options while preserving Rstest's `output.path`; Rstest retains `iife`, `importFunctionName`, and `devtoolModuleFilenameTemplate`                                                                              |
| `resolve`          | Merges Rspack-only options (`fallback`, `byDependency`, `extensionAlias`, `preferRelative`, `tsConfig`, etc.); `alias: false` clears aliases, while Rstest keeps required `.cjs`, `extensionAlias`, and Node/CommonJS defaults |
| `experiments`      | Merges `experiments`, while Rstest retains `runtimeMode: 'webpack'` and disables `asyncWebAssembly`                                                                                                                            |
| `optimization`     | Merges `optimization`, while Rstest retains its shared `runtimeChunk` and `emitOnErrors: true`                                                                                                                                 |
| `devtool`          | Keeps inline source map variants; Rstest normalizes non-inline or unset values to `'nosources-source-map'`                                                                                                                     |
| `watchOptions`     | Merges watch options used when Rstest runs in watch mode                                                                                                                                                                       |
| `externalsPresets` | Merges compatible presets, then sets `node: false` so Rstest can assign external types per request                                                                                                                             |
| `cache`            | Applies `false` or `{ type: 'memory' }` directly; for `{ type: 'persistent' }`, Rstest regenerates the cache config while preserving the resolved `storage.location`                                                           |

:::warning
Because the adapter removes Rsbuild's built-in CSS plugins (`rsbuild:css`, `rsbuild:less`, `rsbuild:sass`), Rsbuild-specific CSS options such as `output.cssModules` are unavailable. Configure CSS rules and loaders in your Rspack config instead.
:::

### Passed through via `mergeConfig`

These options do not conflict with Rstest's test build structure and are merged onto the base Rspack config via Rsbuild's `mergeConfig`:

| Rspack option           | Behavior                                                                                                          |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `externals`             | Merges user externals with Rstest's generated externals                                                           |
| `externalsType`         | Sets the default type for user externals that omit one; Rstest-generated externals specify their type per request |
| `infrastructureLogging` | Merges compiler and plugin infrastructure logging options                                                         |
| `loader`                | Merges custom values exposed on the loader context                                                                |
| `ignoreWarnings`        | Appends user warning filters to Rstest's generated filters                                                        |
| `resolveLoader`         | Merges loader resolution options                                                                                  |
| `amd`                   | Applies `require.amd` and `define.amd` values                                                                     |
| `incremental`           | Applies Rspack incremental build settings (Rspack may normalize presets such as `'safe'` into concrete options)   |

### Ignored or controlled by Rstest

These options describe application entry points, multi-compiler orchestration, dev servers, or output owned by Rstest, so the adapter does not forward them:

| Rspack option     | Reason                                                                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `dependencies`    | Rstest converts a single config rather than running a multi-compiler                                                            |
| `extends`         | Rspack CLI resolves extended configs while loading the file, before conversion                                                  |
| `entry`           | Rstest generates entry points from test files                                                                                   |
| `output.path`     | Rstest controls the output directory                                                                                            |
| `context`         | Rstest sets compiler `context` to project root; Rspack `context` only resolves cache paths                                      |
| `mode`            | Rstest sets compiler `mode` from `NODE_ENV` (`'production'` or `'development'`); Rspack `mode` only contributes to cache naming |
| `node`            | Rstest preserves each source module's filename and directory                                                                    |
| `stats`           | Rstest controls compiler stats extraction and reporter output                                                                   |
| `bail`            | Rstest controls compilation error handling                                                                                      |
| `performance`     | Application bundle size hints do not apply to generated test bundles                                                            |
| `watch`           | Rstest controls compiler watch mode                                                                                             |
| `devServer`       | Rstest does not run the Rspack dev server                                                                                       |
| `lazyCompilation` | Rstest does not use Rspack lazy compilation                                                                                     |
| `snapshot`        | Top-level `snapshot` is ignored                                                                                                 |

Persistent-cache tuning fields such as `cache.snapshot`, `maxAge`, `portable`, and `readonly` are also not copied to Rstest's generated build cache.

## Debug config

Run with `DEBUG=rstest` to write the resolved Rstest, Rsbuild, and Rspack configurations to disk. See [Debug mode](/guide/debug/debugging#debug-mode).
