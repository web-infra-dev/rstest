# Mock instance

`MockInstance` is the type of all mock and spy instances, providing methods and state for controlling and inspecting mocks.

## getMockName

- **Type:** `() => string`

Returns the mock name set by `.mockName()`, or the default name (`'rstest.fn()'` or the spied method name).

```ts
const fn = rs.fn();
fn.mockName('myMock');
expect(fn.getMockName()).toBe('myMock');
```

## mockName

- **Type:** `(name: string) => this`

Sets the mock name for this mock instance, shown in assertion errors and debug output.

```ts
const fn = rs.fn();
fn.mockName('logger');
```

## mockClear

- **Type:** `() => this`

Clears all recorded call state (`calls`, `instances`, `contexts`, `invocationCallOrder`, `lastCall`, `results`, and `settledResults`).

```ts
const fn = rs.fn();
fn(1);
fn.mockClear();
expect(fn.mock.calls.length).toBe(0);
```

## mockReset

- **Type:** `() => this`

Calls `mockClear()` and resets the implementation to its initial state.

```ts
const fn = rs.fn().mockImplementation(() => 1);
fn.mockReset();
// Implementation is reset
```

## mockRestore

- **Type:** `() => void`

Calls `mockReset()`, restores the original property descriptor on spied objects, and resets the mock name.

```ts
const obj = { foo: () => 1 };
const spy = rs.spyOn(obj, 'foo');
spy.mockRestore();
```

## Symbol.dispose

<ApiMeta addedVersion="0.10.2" />

- **Type:** `() => void`

Calls `mockRestore()` when the mock leaves a `using` block.

```ts
const obj = { foo: () => 1 };

{
  using spy = rs.spyOn(obj, 'foo').mockImplementation(() => 2);
  expect(obj.foo()).toBe(2);
}

expect(obj.foo()).toBe(1);
```

## getMockImplementation

- **Type:** `() => NormalizedProcedure<T> | undefined`

Returns the current mock implementation function, if one is set (where `NormalizedProcedure<T>` is `(...args: Parameters<T>) => ReturnType<T>`).

```ts
const fn = rs.fn(() => 123);
const impl = fn.getMockImplementation();
```

## mockImplementation

- **Type:** `(fn: NormalizedProcedure<T>) => this`

Sets the implementation function for the mock.

```ts
const fn = rs.fn();
fn.mockImplementation((a: number, b: number) => a + b);
```

## mockImplementationOnce

- **Type:** `(fn: NormalizedProcedure<T>) => this`

Sets the implementation function for the next call only.

```ts
const fn = rs.fn();
fn.mockImplementationOnce(() => 1);
fn(); // returns 1
fn(); // returns undefined
```

## withImplementation

- **Type:** `<T2>(fn: NormalizedProcedure<T>, callback: () => T2) => T2 extends Promise<unknown> ? Promise<this> : this`

Temporarily replaces the mock implementation while `callback` runs, then restores the previous implementation (including any queued `mockImplementationOnce` entries). Returns the mock instance, or a promise resolving to it if `callback` returns a promise.

```ts
const fn = rs.fn(() => 1);
fn.withImplementation(
  () => 2,
  () => {
    expect(fn()).toBe(2);
  },
);
expect(fn()).toBe(1);
```

## mockReturnThis

- **Type:** `() => this`

Configures the mock to return `this` when called.

```ts
const fn = rs.fn();
fn.mockReturnThis();
const obj = { fn };
expect(obj.fn()).toBe(obj);
```

## mockReturnValue

- **Type:** `(value: ReturnType<T>) => this`

Configures the mock to always return `value`.

```ts
const fn = rs.fn();
fn.mockReturnValue(42);
expect(fn()).toBe(42);
```

## mockReturnValueOnce

- **Type:** `(value: ReturnType<T>) => this`

Configures the mock to return `value` for the next call only.

```ts
const fn = rs.fn();
fn.mockReturnValueOnce(1);
expect(fn()).toBe(1);
expect(fn()).toBe(undefined);
```

## mockThrow

<ApiMeta addedVersion="0.11.4" />

- **Type:** `(value: unknown) => this`

Configures the mock to throw `value` whenever it is called.

```ts
const fn = rs.fn().mockThrow(new Error('fail'));
expect(() => fn()).toThrow('fail');
```

## mockThrowOnce

<ApiMeta addedVersion="0.11.4" />

- **Type:** `(value: unknown) => this`

Configures the mock to throw `value` on the next call only.

```ts
const fn = rs.fn(() => 'ok').mockThrowOnce(new Error('fail'));
expect(() => fn()).toThrow('fail');
expect(fn()).toBe('ok');
```

## mockResolvedValue

- **Type:** `(value: Awaited<ReturnType<T>>) => this`

Configures the mock to return a promise that resolves to `value`.

```ts
const fn = rs.fn();
fn.mockResolvedValue(123);
await expect(fn()).resolves.toBe(123);
```

## mockResolvedValueOnce

- **Type:** `(value: Awaited<ReturnType<T>>) => this`

Configures the mock to return a promise that resolves to `value` for the next call only.

```ts
const fn = rs.fn();
fn.mockResolvedValueOnce(1);
await expect(fn()).resolves.toBe(1);
await expect(fn()).resolves.toBe(undefined);
```

## mockRejectedValue

- **Type:** `(error: unknown) => this`

Configures the mock to return a promise that rejects with `error`.

```ts
const fn = rs.fn();
fn.mockRejectedValue(new Error('fail'));
await expect(fn()).rejects.toThrow('fail');
```

## mockRejectedValueOnce

- **Type:** `(error: unknown) => this`

Configures the mock to return a promise that rejects with `error` for the next call only.

```ts
const fn = rs.fn();
fn.mockRejectedValueOnce(new Error('fail'));
await expect(fn()).rejects.toThrow('fail');
await expect(fn()).resolves.toBe(undefined);
```

## mock

Holds recorded call state for the mock, including arguments, return values, instances, and `this` contexts.

```ts
const fn = rs.fn((a: number, b: number) => a + b);
fn(1, 2);
expect(fn.mock.calls[0]).toEqual([1, 2]);
```

### mock.calls

- **Type:** `Parameters<T>[]`

An array containing the arguments for each call to the mock function.

```ts
const fn = rs.fn((a: number, b: number) => a + b);
fn(1, 2);
fn(3, 4);
console.log(fn.mock.calls); // [[1, 2], [3, 4]]
```

### mock.instances

- **Type:** `ReturnType<T>[]`

An array containing the instances instantiated from the mock when called as a constructor.

```ts
const Fn = rs.fn(function (this: { x: number }) {
  this.x = 1;
});
const a = new Fn();
const b = new Fn();
console.log(Fn.mock.instances); // [a, b]
```

### mock.contexts

- **Type:** `ThisParameterType<T>[]`

An array containing the `this` context for each call to the mock function.

```ts
const fn = rs.fn();
const context = {};

fn.apply(context);
fn.call(context);

expect(fn.mock.contexts[0]).toBe(context);
expect(fn.mock.contexts[1]).toBe(context);
```

### mock.invocationCallOrder

- **Type:** `number[]`

An array of numbers representing the global execution order across all mocks, starting at `1`.

```ts
const fn1 = rs.fn();
const fn2 = rs.fn();
fn1();
fn2();
fn1();
console.log(fn1.mock.invocationCallOrder); // [1, 3]
console.log(fn2.mock.invocationCallOrder); // [2]
```

### mock.lastCall

- **Type:** `Parameters<T> | undefined`

The arguments of the last call to the mock function, or `undefined` if it has not been called.

```ts
const fn = rs.fn();
fn(1, 2);
fn(3, 4);
console.log(fn.mock.lastCall); // [3, 4]
```

### mock.results

- **Type:** `MockResult<ReturnType<T>>[]`

An array containing the synchronous result of each call (`{ type: 'return', value }`, `{ type: 'throw', value }`, or `{ type: 'incomplete', value: undefined }`).

```ts
const fn = rs.fn((a: number) => {
  if (a < 0) {
    throw new Error('fail');
  }
  return a * 2;
});
fn(2);
try {
  fn(-1);
} catch {}
console.log(fn.mock.results);
// [{ type: 'return', value: 4 }, { type: 'throw', value: Error }]
```

### mock.settledResults

- **Type:** `MockSettledResult<Awaited<ReturnType<T>>>[]`

An array containing the settled outcomes (`{ type: 'fulfilled', value }` or `{ type: 'rejected', value }`) for calls whose return value is a promise.

```ts
const fn = rs.fn(async (x: number) => {
  if (x > 0) return x;
  throw new Error('fail');
});
await fn(1);
try {
  await fn(0);
} catch {}
console.log(fn.mock.settledResults);
// [{ type: 'fulfilled', value: 1 }, { type: 'rejected', value: Error }]
```
