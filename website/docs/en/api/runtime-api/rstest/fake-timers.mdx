# Fake timers

Fake timers replace global timer functions and `Date` so tests can control time without waiting for real timeouts, powered by [@sinonjs/fake-timers](https://github.com/sinonjs/fake-timers).

## rs.useFakeTimers

- **Alias:** `rstest.useFakeTimers`
- **Type:** `(config?: FakeTimerInstallOpts) => RstestUtilities & Disposable`

Enables fake timers for `setTimeout`, `setInterval`, `Date`, `performance`, and related timer APIs (excluding `Intl`, `nextTick`, and `queueMicrotask` by default).

```ts
rs.useFakeTimers();
```

Pass `config` (`FakeTimerInstallOpts` from `@sinonjs/fake-timers`, not re-exported by `@rstest/core`) to forward options to `@sinonjs/fake-timers`: for example, `toFake` and `toNotFake` to select timer APIs, `now` to set the initial fake time, and `shouldAdvanceTime` / `advanceTimeDelta` for automatic advancement.

- **`using` syntax**

<ApiMeta addedVersion="0.10.3" />

`rs.useFakeTimers()` returns a `Disposable` that restores real timers when the `using` block exits (`using` requires a binding variable such as `_timers`):

```ts
{
  using _timers = rs.useFakeTimers();
  // Fake timers are active in this block.
}

// Real timers are restored.
```

## rs.useRealTimers

- **Alias:** `rstest.useRealTimers`
- **Type:** `() => RstestUtilities`

Restores the original timer functions and `Date`, disabling fake timers.

```ts
rs.useRealTimers();
```

## rs.isFakeTimers

- **Alias:** `rstest.isFakeTimers`
- **Type:** `() => boolean`

Returns `true` if fake timers are currently enabled, otherwise `false`.

```ts
if (rs.isFakeTimers()) {
  // Fake timers are active
}
```

## rs.setSystemTime

- **Alias:** `rstest.setSystemTime`
- **Type:** `(now?: number | Date | { epochMilliseconds: number }) => RstestUtilities`

Sets the current system time.

When fake timers are enabled, this updates the fake clock (affecting `Date` without changing `performance.now()`) without firing any timers. When fake timers are not enabled, it mocks `Date` only, so you can pin the date without calling [`rs.useFakeTimers`](#rsusefaketimers) first.

`now` also accepts Temporal-like objects with `epochMilliseconds` (such as `Temporal.Instant` or `Temporal.ZonedDateTime`).

```ts
rs.setSystemTime(new Date('2020-01-01T00:00:00Z'));

expect(new Date().toISOString()).toBe('2020-01-01T00:00:00.000Z');

rs.useRealTimers();
```

## rs.getRealSystemTime

- **Alias:** `rstest.getRealSystemTime`
- **Type:** `() => number`

Returns the real system timestamp in milliseconds, even when fake timers are enabled.

```ts
const realTime = rs.getRealSystemTime();
```

## rs.getRealTimers

<ApiMeta addedVersion="0.11.1" />

- **Alias:** `rstest.getRealTimers`
- **Type:** `() => { setTimeout: typeof globalThis.setTimeout; clearTimeout: typeof globalThis.clearTimeout; setImmediate?: typeof globalThis.setImmediate }`

Returns the real timer functions captured by Rstest, even when fake timers are enabled.

```ts
const { setTimeout, clearTimeout } = rs.getRealTimers();

const timeout = setTimeout(() => {
  // Runs on real time.
}, 1000);

clearTimeout(timeout);
```

## rs.runAllTicks

- **Alias:** `rstest.runAllTicks`
- **Type:** `() => RstestUtilities`

Runs all queued microtasks scheduled by faked microtask APIs (such as `process.nextTick` and `queueMicrotask` when included in `toFake`).

## rs.runAllTimers

- **Alias:** `rstest.runAllTimers`
- **Type:** `() => RstestUtilities`

Executes all pending timers (both timeouts and intervals), including any timers scheduled during execution.

## rs.runAllTimersAsync

- **Alias:** `rstest.runAllTimersAsync`
- **Type:** `() => Promise<RstestUtilities>`

Asynchronously executes all pending timers, flushing microtasks between timer callbacks.

## rs.runOnlyPendingTimers

- **Alias:** `rstest.runOnlyPendingTimers`
- **Type:** `() => RstestUtilities`

Executes only the timers currently pending; any new timers scheduled during execution are not run.

## rs.runOnlyPendingTimersAsync

- **Alias:** `rstest.runOnlyPendingTimersAsync`
- **Type:** `() => Promise<RstestUtilities>`

Asynchronously executes only the timers currently pending, flushing microtasks between timer callbacks.

## rs.advanceTimersByTime

- **Alias:** `rstest.advanceTimersByTime`
- **Type:** `(ms: number | string | TemporalDuration) => RstestUtilities`

Advances fake timers by the specified duration, executing any timers scheduled within that window.

String durations follow `@sinonjs/fake-timers` format (for example, `'00:10'` for ten seconds), and `TemporalDuration` accepts `@sinonjs/fake-timers`'s structural Temporal duration object shape.

## rs.advanceTimersByTimeAsync

- **Alias:** `rstest.advanceTimersByTimeAsync`
- **Type:** `(ms: number | string | TemporalDuration) => Promise<RstestUtilities>`

Asynchronously advances fake timers by the specified duration, flushing microtasks between timer callbacks.

## rs.advanceTimersToNextTimer

- **Alias:** `rstest.advanceTimersToNextTimer`
- **Type:** `(steps?: number) => RstestUtilities`

Advances fake timers to the next scheduled timer, repeating up to `steps` times (default: `1`).

## rs.advanceTimersToNextTimerAsync

- **Alias:** `rstest.advanceTimersToNextTimerAsync`
- **Type:** `(steps?: number) => Promise<RstestUtilities>`

Asynchronously advances fake timers to the next scheduled timer, repeating up to `steps` times (default: `1`).

## rs.advanceTimersToNextFrame

- **Alias:** `rstest.advanceTimersToNextFrame`
- **Type:** `() => RstestUtilities`

Advances fake timers to the next animation frame.

## rs.jumpTimersByTime

<ApiMeta addedVersion="0.11.0" />

- **Alias:** `rstest.jumpTimersByTime`
- **Type:** `(ms: number | string | TemporalDuration) => RstestUtilities`

Jumps the fake clock forward by the specified duration, firing each affected timer callback at most once (skipping intermediate interval ticks, like waking a suspended process).

```ts
rs.useFakeTimers({ now: 0 });

const cb = rs.fn();
setInterval(cb, 1000);

rs.jumpTimersByTime(5000);

expect(cb).toHaveBeenCalledTimes(1);
```

## rs.setTickMode

<ApiMeta addedVersion="0.11.0" />

- **Alias:** `rstest.setTickMode`
- **Type:** `(mode: { mode: 'manual' | 'nextAsync' } | { mode: 'interval'; delta?: number }) => RstestUtilities`

Configures how fake timers advance automatically:

- `{ mode: 'manual' }`: timers only advance via explicit calls such as `rs.advanceTimersByTime()`.
- `{ mode: 'nextAsync' }`: continuously advances to the next scheduled timer and lets promise callbacks run between timers.
- `{ mode: 'interval', delta?: number }`: advances fake time on an interval (equivalent to `shouldAdvanceTime` / `advanceTimeDelta`).

```ts
rs.useFakeTimers();
rs.setTickMode({ mode: 'nextAsync' });

await new Promise((resolve) => setTimeout(resolve, 1000));
```

## rs.getTimerCount

- **Alias:** `rstest.getTimerCount`
- **Type:** `() => number`

Returns the number of pending fake timers.

```ts
const count = rs.getTimerCount();
```

## rs.clearAllTimers

- **Alias:** `rstest.clearAllTimers`
- **Type:** `() => RstestUtilities`

Removes all scheduled fake timers without executing them.

```ts
rs.clearAllTimers();
```
