# Rstest utility

Rstest provides test utilities for mocking, fake timers, and environment stubbing through the `rs` helper.

Import `rs` directly from `@rstest/core`:

```ts
import { rs } from '@rstest/core';

const fn = rs.fn();
fn.mockResolvedValue('foo');
```

`rstest` is available as an alias for `rs`:

```ts
import { rstest } from '@rstest/core';

const fn = rstest.fn();
fn.mockResolvedValue('foo');
```

When [globals](/config/test/globals) is enabled, both `rs` and `rstest` are available globally without importing.
