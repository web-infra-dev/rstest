# Mock functions

Rstest provides utility functions for creating mock functions, spying on object methods, and deep-mocking objects, powered by [tinyspy](https://github.com/tinylibs/tinyspy).

## rs.fn

- **Alias:** `rstest.fn`
- **Type:**

```ts
type FunctionLike = (...args: any) => any;

export interface Mock<
  T extends FunctionLike = FunctionLike,
> extends MockInstance<T> {
  new (...args: Parameters<T>): ReturnType<T>;
  (...args: Parameters<T>): ReturnType<T>;
}

export type MockFn = <T extends FunctionLike = FunctionLike>(fn?: T) => Mock<T>;
```

Creates a mock function, optionally wrapping an initial implementation `fn`.

See [`Mock`](/api/javascript-api/types#mock) for typing callable mock functions.

```ts
const sayHi = rs.fn((name: string) => `hi ${name}`);

const res = sayHi('bob');

expect(res).toBe('hi bob');
expect(sayHi).toHaveBeenCalledTimes(1);
```

## rs.spyOn

- **Alias:** `rstest.spyOn`
- **Type:**

```ts
export type SpyFn = <T extends Record<string, any>, K extends keyof T>(
  obj: T,
  methodName: K,
  accessType?: 'get' | 'set',
) => MockInstance<T[K]>;
```

Creates a spy on a method or property accessor (`'get'` or `'set'` via `accessType`) of an object while keeping the original implementation until overridden.

See [`MockInstance`](/api/javascript-api/types#mockinstance) for the control API returned by a spy.

```ts
const sayHi = () => 'hi';
const hi = {
  sayHi,
};

const spy = rs.spyOn(hi, 'sayHi');

expect(hi.sayHi()).toBe('hi');
expect(spy).toHaveBeenCalled();
```

Calling `rs.spyOn` multiple times on the same method reuses the existing spy instead of wrapping it again:

```ts
const hi = {
  sayHi: () => 'hi',
};
rs.spyOn(hi, 'sayHi').mockImplementation(() => 'hello');

expect(hi.sayHi()).toBe('hello');
// Returns the same spy instance
expect(rs.spyOn(hi, 'sayHi')).toHaveBeenCalled();
```

:::note Spying on re-exported or third-party exports

`rs.spyOn` works on exports defined in the imported module, but not on read-only exports **re-exported** from another module (`export * from '...'`) or exposed by native/third-party ES modules.

For those cases, mock the module with [`{ spy: true }`](/api/runtime-api/rstest/mock-modules#with-spy-true-option) to wrap every export in a spy while preserving the original implementation:

```ts
rs.mock('pkg', { spy: true });
```

:::

## rs.isMockFunction

- **Alias:** `rstest.isMockFunction`
- **Type:** `(fn: any) => fn is MockInstance`

Returns `true` if `fn` is a mock function and narrows its type to [`MockInstance`](./mock-instance).

## rs.mockObject

- **Alias:** `rstest.mockObject`
- **Type:**

```ts
type MockObject = <T>(
  object: T,
  options?: { spy?: boolean },
) => MaybeMockedDeep<T>;
```

Creates a deep mock of an object. Functions are replaced with mock functions (recursively across plain objects), while primitive values and built-in objects such as `Date`, `RegExp`, and `Map` are preserved.

### Basic usage

```ts
const original = {
  method() {
    return 42;
  },
  nested: {
    getValue() {
      return 'real';
    },
  },
  prop: 'foo',
};

const mocked = rs.mockObject(original);

// Methods return undefined by default
expect(mocked.method()).toBe(undefined);
expect(mocked.nested.getValue()).toBe(undefined);

// Primitive values are preserved
expect(mocked.prop).toBe('foo');

// Methods are mock functions
expect(rs.isMockFunction(mocked.method)).toBe(true);
```

### Mocking return values

```ts
const mocked = rs.mockObject({
  fetchData: () => 'real data',
});

mocked.fetchData.mockReturnValue('mocked data');

expect(mocked.fetchData()).toBe('mocked data');
```

### Spy mode

Pass `{ spy: true }` as the second argument to keep original implementations while tracking calls:

```ts
const original = {
  add: (a: number, b: number) => a + b,
};

const spied = rs.mockObject(original, { spy: true });

expect(spied.add(1, 2)).toBe(3);
expect(spied.add).toHaveBeenCalledWith(1, 2);
expect(spied.add.mock.results[0]).toEqual({ type: 'return', value: 3 });
```

### Arrays

By default, arrays are replaced with empty arrays. With `{ spy: true }`, array elements are preserved (and any nested functions or plain objects inside are spied):

```ts
const mocked = rs.mockObject({ array: [1, 2, 3] });
expect(mocked.array).toEqual([]);

const spied = rs.mockObject({ array: [1, 2, 3] }, { spy: true });
expect(spied.array).toEqual([1, 2, 3]);
```

### Mocking classes

Pass a class constructor to mock it. With `{ spy: true }`, instances retain their original methods as spies:

```ts
class UserService {
  getUser() {
    return { id: 1, name: 'Alice' };
  }
}

const MockedService = rs.mockObject(UserService, { spy: true });
const instance = new MockedService();

expect(instance.getUser()).toEqual({ id: 1, name: 'Alice' });

rs.mocked(instance.getUser).mockImplementation(() => ({ id: 2, name: 'Bob' }));
expect(instance.getUser()).toEqual({ id: 2, name: 'Bob' });
```

## rs.mocked

- **Alias:** `rstest.mocked`
- **Type:**

```ts
type MockedFn = (<T>(item: T, deep?: false) => Mocked<T>) &
  (<T>(item: T, deep: true) => MaybeMockedDeep<T>) &
  (<T>(item: T, options: { partial?: false; deep?: false }) => Mocked<T>) &
  (<T>(
    item: T,
    options: { partial?: false; deep: true },
  ) => MaybeMockedDeep<T>) &
  (<T>(
    item: T,
    options: { partial: true; deep?: false },
  ) => MaybePartiallyMocked<T>) &
  (<T>(
    item: T,
    options: { partial: true; deep: true },
  ) => MaybePartiallyMockedDeep<T>);
```

A TypeScript type helper that returns `item` unchanged at runtime while typing its methods as mocks. Pass `true` or `{ deep: true }` to apply mock types recursively, or `{ partial: true }` to use partial mock variants.

See [`Mocked`](/api/javascript-api/types#mocked) for annotating mocked objects and modules.

```ts
import { myModule } from './myModule';

rs.mock('./myModule', { spy: true });

// TypeScript now knows myModule.method is a MockInstance
const mockedModule = rs.mocked(myModule);

mockedModule.method.mockReturnValue('mocked');
```

## rs.clearAllMocks

- **Alias:** `rstest.clearAllMocks`
- **Type:** `() => RstestUtilities`

Calls `.mockClear()` on all mocks, clearing their call history (`mock.calls`, `mock.instances`, `mock.contexts`, `mock.invocationCallOrder`, `mock.lastCall`, `mock.results`, and `mock.settledResults`).

## rs.resetAllMocks

- **Alias:** `rstest.resetAllMocks`
- **Type:** `() => RstestUtilities`

Calls `.mockReset()` on all mocks, clearing all call history and resetting each mock's implementation to its initial state.

## rs.restoreAllMocks

- **Alias:** `rstest.restoreAllMocks`
- **Type:** `() => RstestUtilities`

Restores the original descriptors of objects spied on with `rs.spyOn()`. Does not clear mock call history or reset mock implementations; standalone mocks created with `rs.fn()` are not affected.
