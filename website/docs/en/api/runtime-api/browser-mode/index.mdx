# Browser mode

[@rstest/browser](https://github.com/web-infra-dev/rstest/tree/main/packages/browser) provides the Browser Mode runtime APIs with a Playwright-style `Locator` workflow.

## Exported API

- [`page`](/api/runtime-api/browser-mode/locator#page): `BrowserPage` entry for element queries, DOM wrapping, [`keyboard`](/api/runtime-api/browser-mode/keyboard) input, and [`viewport`](/api/runtime-api/browser-mode/locator#pageviewport) resizing
- [`Locator`](/api/runtime-api/browser-mode/locator): Class for chained element queries and interactions
- [`BrowserPage`](/api/runtime-api/browser-mode/locator#browserpage): Type definition for `page`
- [`setTestIdAttribute`](/api/runtime-api/browser-mode/locator#settestidattribute): Configures the attribute name used by `getByTestId()`

`@rstest/browser` also exports option and assertion types such as `BrowserElementExpect`, `ToMatchScreenshotOptions`, `LocatorClickOptions`, `LocatorGetByRoleOptions`, and `BrowserKeyboard`.

## Assertion API

Importing `@rstest/browser` in a Browser Mode test extends `@rstest/core`'s `expect` with:

- [`expect.element(target)`](/api/runtime-api/browser-mode/assertion): Auto-retrying DOM assertions on a `Locator` or DOM `Element`
- [`toMatchScreenshot()`](/api/runtime-api/browser-mode/assertion#toMatchScreenshot): Visual screenshot comparison on a `Locator` or `page`

## Example: query, interaction, and assertion

```ts title="browser-example.test.ts"
import { page } from '@rstest/browser';
import { expect, test } from '@rstest/core';

test('submits form', async () => {
  await page.getByLabel('Email').fill('dev@rstest.rs');
  await page.getByRole('button', { name: 'Submit' }).click();
  await expect.element(page.getByText('Done')).toBeVisible();
});
```
