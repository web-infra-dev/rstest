# Hooks

Register setup and teardown callbacks for suites and individual tests.

## beforeAll

- **Type:**

```ts
interface SuiteContext {
  filepath: string;
  meta: TaskMeta;
}

type BeforeAll = (
  fn: (
    ctx: SuiteContext,
  ) =>
    | void
    | ((ctx: SuiteContext) => void | Promise<void>)
    | Promise<void | ((ctx: SuiteContext) => void | Promise<void>)>,
  timeout?: number,
) => void;
```

Runs once before any test in the current suite (or once for the file when called at top level).

Rstest skips `beforeAll` when the suite has no runnable tests — for example, when all tests are skipped, filtered out by name, or unselected by `test.only`.

```ts
import { beforeAll } from '@rstest/core';

beforeAll(async (ctx) => {
  // ctx.filepath holds the current test file path
  ctx.meta.startedAt = Date.now();
});
```

Returning a function from `beforeAll` registers a suite cleanup callback that runs after the suite's `afterAll` hooks, in the order configured by [`sequence.hooks`](/config/test/sequence#sequencehooks):

```ts
import { beforeAll } from '@rstest/core';

beforeAll(async () => {
  const resource = await acquireResource();

  return async () => {
    await resource.close();
  };
});
```

## afterAll

- **Type:** `(fn: (ctx: SuiteContext) => void | Promise<void>, timeout?: number) => void`

Runs once after all tests in the current suite finish. Skipped when the suite has no runnable tests.

```ts
import { afterAll } from '@rstest/core';

afterAll(async (ctx) => {
  ctx.meta.finished = true;
});
```

<ApiMeta addedVersion="0.11.1" />

`ctx.meta` is the mutable metadata object for the current suite. When a suite is declared with `describe(name, { meta }, fn)`, `ctx.meta` starts with the inherited metadata. File-level hooks write to `TestFileResult.meta`; hooks inside `describe` write to that suite's `TestResult.meta` in custom reporters.

## beforeEach

- **Type:** `<ExtraContext = object>(fn: (ctx: TestContext & ExtraContext) => void | ((ctx: TestContext & ExtraContext) => void | Promise<void>) | Promise<void | ((ctx: TestContext & ExtraContext) => void | Promise<void>)>, timeout?: number) => void`

Runs before each test in the current suite. See [`TestContext`](/api/runtime-api/test-api/test#testcontext) for the fields on `ctx` (same for `afterEach`, `onTestFinished`, and `onTestFailed`).

```ts
import { beforeEach } from '@rstest/core';

beforeEach(async () => {
  // Setup logic before each test
});
```

Returning a function from `beforeEach` registers a per-test cleanup callback that runs after all `afterEach` hooks for that test, in the order configured by [`sequence.hooks`](/config/test/sequence#sequencehooks):

```ts
import { beforeEach } from '@rstest/core';

beforeEach(async () => {
  const handle = await openHandle();

  return async () => {
    await handle.close();
  };
});
```

<ApiMeta addedVersion="0.11.4" />

`beforeEach`, `afterEach`, and cleanups returned from `beforeEach` can consume fixtures created with `test.extend`. Pass the fixture interface as `ExtraContext` and destructure the required fixtures directly in the callback parameter. Rstest does not infer fixture dependencies from the hook body, and object rest properties or default values are not supported. See [Using fixtures in hooks](/api/runtime-api/test-api/test#using-fixtures-in-hooks).

## afterEach

- **Type:** `<ExtraContext = object>(fn: (ctx: TestContext & ExtraContext) => void | Promise<void>, timeout?: number) => void`

Runs after each test in the current suite.

```ts
import { afterEach } from '@rstest/core';

afterEach(async () => {
  // Cleanup logic after each test
});
```

## onTestFinished

- **Type:** `(fn: (ctx: TestContext) => void | Promise<void>, timeout?: number) => void`

Registers a callback that runs after the current test finishes, regardless of whether it passed or failed. Runs after `afterEach`. Must be called inside a running test.

```ts
import { onTestFinished, test } from '@rstest/core';

test('closes server after test', () => {
  const server = startServer();
  onTestFinished(() => server.close());

  server.listen(3000);
});
```

In concurrent tests, read `onTestFinished` from the test context parameter rather than the top-level import so Rstest binds the cleanup to that specific test:

```ts
import { describe, test } from '@rstest/core';

describe.concurrent('concurrent suite', () => {
  test('test 1', async ({ onTestFinished }) => {
    /* ... */
  });
  test('test 2', async ({ onTestFinished }) => {
    /* ... */
  });
});
```

## onTestFailed

- **Type:** `(fn: (ctx: TestContext) => void | Promise<void>, timeout?: number) => void`

Registers a callback that runs only when the current test fails. Must be called inside a running test.

```ts
import { onTestFailed, test } from '@rstest/core';

test('logs errors on failure', () => {
  onTestFailed(({ task }) => {
    console.log(task.result?.errors);
  });
});
```

In concurrent tests, read `onTestFailed` from the test context parameter rather than the top-level import so Rstest binds the hook to that specific test.
