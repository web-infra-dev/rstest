Rstest provides runtime APIs for writing tests, mocking, browser automation, and reading test-runner environment state:

- [Test API](/api/runtime-api/test-api/expect): `expect`, `assert`, `test`, `describe`, and lifecycle hooks.
- [Browser Mode](/api/runtime-api/browser-mode/): `page`, `Locator`, keyboard actions, `expect.element`, and React testing utilities.
- [Rstest utility](/api/runtime-api/rstest/): `rs` / `rstest` helpers for mocking, fake timers, stubbing, runtime config, and polling.
- [Environment variables](/api/runtime-api/environment-variables): environment variables set or read by Rstest.
