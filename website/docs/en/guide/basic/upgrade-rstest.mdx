# Upgrade Rstest

Use [Taze](https://github.com/antfu-collective/taze) to update Rstest packages in `package.json` to the latest release.

:::info
Rstest is in `0.x`, so minor versions can introduce breaking changes. Check the release notes before upgrading across minor versions.
:::

## Using taze

### Usage

Update all dependencies whose names contain `rstest` or `rsbuild`:

```bash
npx taze major --include "/(rstest|rsbuild)/" -w
```

:::tip Why `major` is required
Because Rstest is still on `0.x`, SemVer treats minor releases such as `0.11` → `0.12` as breaking changes. Without `major`, `taze` only updates patch releases within the same minor range.
:::

Example output:

```bash
rstest-example - 1 minor

  devDependencies
    @rstest/core    ~14d  ^0.11.0  →  ^0.12.6  ~1d

ℹ changes written to package.json, run pnpm i to install updates.
```

Then run your package manager's install command (`pnpm install`, `npm install`, etc.) to install the updated packages.

To update only packages under the `@rstest` scope:

```bash
npx taze major --include "/@rstest/" -w
```

### Options

- Upgrade recursively across all packages in a monorepo (`-r`):

```bash
npx taze major --include "/(rstest|rsbuild)/" -w -r
```

- Upgrade locked dependency versions (`-l`):

```bash
npx taze major --include "/(rstest|rsbuild)/" -w -l
```

For additional options, see the [Taze documentation](https://github.com/antfu-collective/taze).
