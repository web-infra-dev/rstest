# VS Code extension

The [Rstack](https://github.com/rstackjs/rstack-editor) VS Code extension integrates Rstest into VS Code's Test Explorer so you can browse, run, and debug tests directly from the editor. A single install covers testing, linting, and formatting across the Rstack toolchain.

## Installation

Install the extension from the [Visual Studio Code Marketplace](https://marketplace.visualstudio.com/items?itemName=rstack.rstack), or directly in VS Code:

- Open the _Extensions_ view (<kbd>Ctrl</kbd>/<kbd title="Cmd">⌘</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>) and search for `rstack.rstack`.
- Open _Quick Open_ (<kbd>Ctrl</kbd>/<kbd title="Cmd">⌘</kbd> + <kbd>P</kbd>), run `ext install rstack.rstack`, and press Enter.
- Or install from the terminal: `code --install-extension rstack.rstack`.

For Cursor, Trae, VSCodium, and other VS Code forks, install it from the [Open VSX Registry](https://open-vsx.org/extension/rstack/rstack).

:::tip Coming from the standalone Rstest extension

The standalone `rstack.rstest` extension is retired and no longer receives new features. It remains published during the transition, but we recommend switching to `rstack.rstack`:

1. Install `rstack.rstack` using one of the methods above.
2. Disable or uninstall `rstack.rstest` so only one copy of Rstest runs.
3. Re-apply your settings under the `rstack.rstest.*` keys and re-bind any keybindings to the `rstack.rstest.*` command IDs, as settings are not migrated automatically. See the [migration notes](https://github.com/rstackjs/rstack-editor/blob/main/packages/vscode/README.md#coming-from-the-standalone-extensions) for details.

:::
