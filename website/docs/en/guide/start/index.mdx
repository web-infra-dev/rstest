# Introduction

Rstest is a JavaScript and TypeScript testing framework built on [Rspack](https://rspack.rs) and [Rsbuild](https://rsbuild.rs). It provides Jest-compatible APIs with built-in support for TypeScript, ESM, CJS, and CSS Modules.

## ✨ Why Rstest

Built on Rspack and Rsbuild, Rstest runs TypeScript, ESM, CJS, and CSS Modules out of the box—you can adopt it without migrating your existing build setup.

If your project already uses Rstack tools (Rspack, Rsbuild, or Rslib), Rstest reuses your existing module resolution, code transforms, and plugins through adapters instead of maintaining a separate test config.

Rstest executes tests with a dependency-graph **bundle model** rather than transforming files one by one. Build-time optimizations—such as tree-shaking and skipping unused re-exports in side-effect-free barrel files—cut redundant module compilation and execution in large projects and keep test behavior closer to production output. See [Module side effects](/guide/advanced/side-effects) for how `sideEffects` declarations affect initialization imports.

## 🔥 Roadmap

Rstest supports Node.js and DOM testing, Browser Mode, Playwright E2E testing, mocking, multi-project workspaces, and code coverage, and is used across Rstack projects including Rsbuild, Rslib, and Rspack.

See the [Rstest Roadmap](https://github.com/web-infra-dev/rstest/issues/85) for upcoming plans.
