# Getting started

This guide will help you configure and run Browser Mode tests in your project.

import { PackageManagerTabs } from '@theme';

## Automatic initialization

The quickest way is to use the `@rstest/core init browser` command for automatic configuration:

<PackageManagerTabs command="@rstest/core init browser" dlx />

### Initialization process

When you run the command, Rstest automatically:

1. **Generates boilerplate code**: Rstest detects your project's framework (React or vanilla DOM), language (TypeScript via `tsconfig.json`, or JavaScript), test directory (`tests/`, `test/`, `__tests__/`, or `src/__tests__/`, defaulting to `tests/`), and package manager, then generates sample components and test files in the detected test directory.

2. **Creates configuration file**: Creates `rstest.browser.config.mts` in your project root with Browser Mode enabled.

3. **Updates `package.json`**: Adds a `test:browser` script (`rstest --config=rstest.browser.config.mts`) and adds `@rstest/browser`, `playwright`, and `@testing-library/dom` (plus `@rstest/browser-react` for React projects) to `devDependencies`.

Here's an example output for a React project:

```bash
Set up Rstest browser mode

  Detecting project...
  ✓ Found React 19.0.0
  ✓ Using playwright as browser provider
  ✓ Test directory: tests/

  Created files:
    - rstest.browser.config.mts
    - tests/Counter.jsx
    - tests/Counter.test.jsx
    - Updated package.json

  Next steps:
    pnpm i
    pnpm dlx playwright install --with-deps
    pnpm run test:browser

└ Done!
```

### Next steps

Follow the printed next steps to install dependencies, download Playwright browsers, and run your browser tests.

:::tip Non-interactive environments
In CI or other non-interactive environments, add `--yes` to skip prompts and use detected defaults:

```bash
npx @rstest/core init browser --yes
```

:::

## Manual configuration

### 1. Install dependencies

Install `@rstest/core` (test runner), `@rstest/browser` (Browser Mode runtime), and `playwright` (browser driver peer dependency):

<PackageManagerTabs command="add @rstest/core @rstest/browser playwright -D" />

Download the Playwright browser binary you want to run tests against:

```bash
npx playwright install chromium
```

You can also install Firefox, WebKit, or all browsers:

```bash
# Install Firefox
npx playwright install firefox

# Install WebKit (Safari)
npx playwright install webkit

# Install all browsers
npx playwright install
```

### 2. Create configuration file

Create or update your `rstest.config.ts` configuration file:

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  browser: {
    enabled: true,
    provider: 'playwright',
  },
});
```

### 3. Write tests

Create a browser test file. The recommended approach is to use the Locator API for element queries and interactions:

```ts title="tests/counter.test.ts"
import { page } from '@rstest/browser';
import { expect, test } from '@rstest/core';

test('counter increments on click', async () => {
  document.body.innerHTML = `
    <button id="count-btn">Count: 0</button>
  `;

  let count = 0;
  document.getElementById('count-btn')!.addEventListener('click', (e) => {
    count++;
    (e.target as HTMLButtonElement).textContent = `Count: ${count}`;
  });

  await expect
    .element(page.getByRole('button', { name: 'Count: 0' }))
    .toBeVisible();
  await page.getByRole('button', { name: 'Count: 0' }).click();
  await expect.element(page.getByText('Count: 1')).toBeVisible();
});
```

This example uses `page.getByRole()` to locate a button by its semantic role, triggers an interaction with `click()`, and asserts the result with `expect.element().toBeVisible()`. The assertion automatically waits for the element state to change — no manual polling needed.

## Headless vs headed mode

By default, Browser Mode automatically selects the running mode based on the environment:

- **CI environment**: Automatically uses headless mode (no UI)
- **Local development**: Uses headed mode by default (shows browser window)

### Configuring headless mode

You can explicitly specify this in your configuration file:

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  browser: {
    enabled: true,
    provider: 'playwright',
    headless: true, // Always use headless mode
  },
});
```
