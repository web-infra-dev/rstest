# env

- **类型：** `Partial<NodeJS.ProcessEnv>`
- **默认值：** `{}`

自定义测试期间通过 `process.env`（以及 `import.meta.env`）暴露的环境变量。

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  env: {
    PRINT_LOGGER: 'true',
  },
});
```

在测试中读取 `process.env.PRINT_LOGGER`：

```ts title="index.test.ts"
import { expect, it } from '@rstest/core';

it('reads custom env', () => {
  expect(process.env.PRINT_LOGGER).toBe('true');
});
```

在 Node Mode 下，`env` 会覆盖继承自宿主进程的 `process.env` 以及 [`globalSetup`](/config/test/global-setup) 中修改的值。在 Browser Mode 下，宿主环境变量不会自动透传（仅内置 `NODE_ENV`、`RSTEST` 以及当前 Browser 项目自身 `globalSetup` 产生的值），`env` 配置同样具有最高优先级。
