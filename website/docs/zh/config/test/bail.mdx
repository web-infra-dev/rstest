# bail

- **类型：** `number`
- **默认值：** `0`
- **CLI：** `--bail [number]`（默认值：`1`）

在指定个数的测试失败后中止测试运行。

设为 `0`（默认值）时会运行全部测试；设为 `1` 时会在第一个测试失败后停止运行。
