# unstubEnvs

- **类型：** `boolean`
- **默认值：** `false`
- **CLI：** `--unstubEnvs`

在每次测试执行前自动调用 [`rs.unstubAllEnvs()`](/api/runtime-api/rstest/utilities#rsunstuballenvs)，将通过 [`rs.stubEnv()`](/api/runtime-api/rstest/utilities#rsstubenv) 修改的所有 `process.env` 和 `import.meta.env` 值恢复为原始值。

<Tabs defaultValue='rstest.config.ts'>

  npx rstest --unstubEnvs

  <Tab label="rstest.config.ts">
