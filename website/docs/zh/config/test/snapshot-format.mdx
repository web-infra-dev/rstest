# snapshotFormat

- **类型：** `Omit<PrettyFormatOptions, 'plugins' | 'compareKeys'>`
- **默认值：** `{ printShadowRoot: false }`

使用 [pretty-format](https://www.npmjs.com/package/pretty-format) 提供的选项自定义快照序列化格式。由于配置需要跨 worker 边界序列化传递，因此不支持 `plugins` 和 `compareKeys`。

Rstest 默认在快照中省略 Shadow Root。将 `printShadowRoot` 设置为 `true` 可包含它们。

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  snapshotFormat: {
    printBasicPrototype: true,
  },
});
```
