# resetMocks

- **类型：** `boolean`
- **默认值：** `false`
- **CLI：** `--resetMocks`

在每个测试前清除所有 mock 状态，并将每个 mock 的实现重置为其原始实现。

启用 `resetMocks` 后，Rstest 会在每个测试执行前调用 [rs.resetAllMocks()](/api/runtime-api/rstest/mock-functions#rsresetallmocks)。
