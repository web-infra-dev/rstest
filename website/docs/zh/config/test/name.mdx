# name

- **类型：** `string`
- **默认值：** `rstest`

测试项目的名称。

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  name: 'node',
});
```

通过 [projects](/config/test/projects) 定义的所有项目名称必须唯一；两个项目重名时，Rstest 会在启动时报错。可通过 [--project](/guide/basic/test-filter#根据项目名称过滤) 选项按名称过滤项目。

如果 project 未提供名称，Rstest 将会使用当前项目的 `package.json` 中定义的 `name` 属性，如果不存在，则使用文件夹名称。
