# disableConsoleIntercept

- **类型：** `boolean`
- **默认值：** `false`
- **CLI：** `--disableConsoleIntercept`

禁用 Rstest 对 `console` 日志的拦截。默认情况下，Rstest 会拦截 `console` 调用以追踪日志所在的测试来源。

import { Tab, Tabs } from '@theme';

<Tabs defaultValue='rstest.config.ts'>
  <Tab label="CLI">
  ```bash
  npx rstest --disableConsoleIntercept
  ```
  </Tab>
  <Tab label="rstest.config.ts">
```ts
import { defineConfig } from '@rstest/core';

export default defineConfig({
  disableConsoleIntercept: true,
});
```
  </Tab>
</Tabs>

设为 `true` 后，[onConsoleLog](/config/test/on-console-log) 和 [printConsoleTrace](/config/test/print-console-trace) 配置不会生效。如果同时启用了 [silent](/config/test/silent)，Rstest 仍会保留一条内部拦截通道，以便 `silent` 继续控制测试日志输出；在 Browser Mode 下，该通道仍会调用原始 `console.*` 供 DevTools 使用。
