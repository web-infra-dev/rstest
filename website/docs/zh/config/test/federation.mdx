# federation

import { ApiMeta } from '@components/ApiMeta';

<ApiMeta addedVersion="0.11.4" />

- **类型：** `boolean`
- **默认值：** `false`
- **CLI：** `--federation`

是否启用[模块联邦（Module Federation）](https://module-federation.io/)支持。

Rstest 在 Node Mode 和 Browser Mode 中均支持模块联邦。基于 Node 的 runner，包括 `testEnvironment: 'node'` 以及 `jsdom`、`happy-dom` 等 DOM 模拟环境，会使用 Rstest 的兼容垫片来支持通过 Node API 加载 chunk 的模块联邦运行时；Node Mode 支持从 Rstest `0.11.4` 开始提供。Browser Mode 则使用打包工具的 Web 端模块联邦运行时，并需要 Rstest `0.11.10` 或更高版本。

Rstest 在单个 worker 运行时中执行测试产物，以保证模块 mock 始终生效。而模块联邦运行时会自行加载远程入口和 chunk，通过 Node 的 `fs`/`vm`/`eval` 或 HTTP，这发生在该运行时之外。启用 `federation` 后，Rstest 会安装额外的运行时垫片，让两者协同工作：

- 为外部化的动态导入提供 `globalThis` 兜底实现，使通过 `vm`/`eval` 执行的模块联邦运行时 chunk 仍能使用 Node 原生动态导入加载模块。
- 防止模块联邦的占位 chunk 处理器（`consumes` / `remotes`）在模块联邦运行时初始化前抛出异常。
- 阻止模块联邦运行时插件替换 Rstest 的 chunk 加载处理器，否则 chunk 会在测试运行时之外执行并丢失 mock。
- 面向 Node 的模块联邦运行会使用 Rstest 的 CommonJS worker loader；Rstest 会将 `output.chunkLoading` 强制为 `'require'`，使 async chunks 通过 Rstest 的模块加载器从内存构建产物中加载，而不经过文件系统。

## 测试联邦应用

`federation` 只负责准备测试运行时，不会配置远程模块、暴露模块或共享依赖。使用 [@module-federation/rstest](https://github.com/module-federation/core) 时，该插件会配置模块联邦构建，并为基于 Node 的测试环境自动启用 Rstest 兼容模式，因此在这些环境下不需要再设置 `federation: true`。Browser Mode 下插件不会启用它，项目用了 `globalSetup` 时要自己设置 `federation: true`。

安装方式和 Rstest 测试流程，请先阅读[模块联邦指南](/guide/advanced/module-federation)。复用已有的 Rsbuild 模块联邦配置以及完整插件选项，请参考 [Rstest 官方集成指南](https://module-federation.io/integrations/build-tool/rstest.html)。

```ts title="rstest.config.ts"
import { federation } from '@module-federation/rstest';
import { defineConfig } from '@rstest/core';

export default defineConfig({
  plugins: [
    federation({
      name: 'main_app',
      remotes: {
        'component-app': 'component_app@http://localhost:3001/remoteEntry.cjs',
      },
      shared: {
        react: { singleton: true },
      },
    }),
  ],
});
```

该 Node 示例消费面向 Node 的 `remoteEntry.cjs`，Browser Mode 应消费浏览器构建的 `remoteEntry.js`。两者的区别请参考[模块联邦指南](/guide/advanced/module-federation)；完整配置可参考 [Node 示例](https://github.com/rstackjs/rstack-examples/tree/main/rstest/module-federation-node)和 [Browser 示例](https://github.com/rstackjs/rstack-examples/tree/main/rstest/module-federation-browser)。
