# clearMocks

- **类型：** `boolean`
- **默认值：** `false`
- **CLI：** `--clearMocks`

在每个测试前自动清除所有 mock 的 `mock.calls`、`mock.instances`、`mock.contexts` 和 `mock.results` 属性。

启用 `clearMocks` 后，Rstest 会在每个测试执行前调用 [rs.clearAllMocks()](/api/runtime-api/rstest/mock-functions#rsclearallmocks)。

import { Tab, Tabs } from '@theme';

<Tabs defaultValue='rstest.config.ts'>


  <Tab label="rstest.config.ts">
```ts

export default defineConfig({

});
```
