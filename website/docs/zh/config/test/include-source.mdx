# includeSource

- **类型：** `string[]`
- **默认值：** `[]`

配置用于匹配源码内联测试（in-source testing）文件的 glob 模式，测试代码与实现代码写在同一个文件中，类似于 [Rust 的模块测试](https://doc.rust-lang.org/book/ch11-03-test-organization.html#the-tests-module-and-cfgtest)。模式会相对于 [root](/config/test/root) 解析，并受 [exclude](/config/test/exclude) 规则约束。

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  includeSource: ['src/**/*.{js,ts}'],
});
```

内联测试适合工具函数等小型模块，方便就近验证和调试。对于较大或需要复杂初始化的模块，建议使用独立的测试文件。

`includeSource` 同时适用于 Node 模式与 [Browser Mode](/guide/browser-testing) 项目。

## 编写内联测试

Rstest 会扫描匹配 `includeSource` 的文件，仅运行其中包含 `import.meta.rstest` 的文件。通过 `import.meta.rstest` 可以获取 Rstest 的测试 API（`it`、`test`、`describe`、`expect` 和 Hook）：

```ts title="src/helper.ts"
export const sayHi = () => 'hi';

if (import.meta.rstest) {
  const { it, expect } = import.meta.rstest;
  it('should return hi', () => {
    expect(sayHi()).toBe('hi');
  });
}
```

## 生产环境构建

将测试代码放在 `if (import.meta.rstest)` 代码块内。构建生产产物时，在构建配置中将 `import.meta.rstest` 定义为 `false`，打包工具即可将其作为死代码消除：

- 使用 Rspack 的 [DefinePlugin](https://rspack.rs/zh/plugins/webpack/define-plugin)：

```diff title="rspack.config.ts"
import { defineConfig } from '@rspack/cli';
+import { rspack } from '@rspack/core';

export default defineConfig({
+  plugins: [
+    new rspack.DefinePlugin({
+      'import.meta.rstest': false,
+    }),
+  ],
});
```

- 使用 Rsbuild 的 [source.define](https://rsbuild.rs/zh/config/source/define) 选项：

```diff title="rsbuild.config.ts"
import { defineConfig } from '@rsbuild/core';

export default defineConfig({
  source: {
    define: {
+      'import.meta.rstest': false,
    },
  },
});
```

## TypeScript

如需为 `import.meta.rstest` 提供 TypeScript 类型支持，在 `tsconfig.json` 的 `compilerOptions.types` 中添加 `@rstest/core/importMeta`：

```json title="tsconfig.json"
{
  "compilerOptions": {
    "types": ["@rstest/core/importMeta"]
  }
}
```

> 如果已有 `compilerOptions.types` 配置，请将该类型追加到现有列表中。

也可以在声明文件中引用该类型：

```ts title="src/rstestEnv.d.ts"
/// <reference types="@rstest/core/importMeta" />
```
