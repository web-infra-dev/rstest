# update

- **类型：** `boolean`
- **默认值：** `false`
- **CLI：** `-u`, `--update`

在测试运行期间更新所有变更的快照、写入缺失的快照，并删除过时的快照。在 Browser Mode 下，这也会替换 [`toMatchScreenshot`](/api/runtime-api/browser-mode/assertion#toMatchScreenshot) 不匹配的截图参考。

默认关闭（`false`）时，已有快照发生变化会报错失败，过时快照也会保留。本地运行时，缺失的快照（包括缺失的截图参考）仍会自动创建；而在 CI 环境中，除非开启 `update`，否则缺失快照同样会导致测试失败。

在 watch mode 下，也可以按 `u` 键触发一次快照更新。
