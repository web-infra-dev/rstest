# testNamePattern

- **类型：** `string | RegExp`
- **默认值：** `undefined`
- **CLI：** `-t=<value>`, `--testNamePattern=<value>`

按 `RegExp` 或正则模式字符串（通过 `new RegExp()` 编译）过滤测试的完整名称。

完整名称将外层 `describe` 套件名称与测试用例名称用空格拼接（当模式中包含 `>` 时改为用 `' > '` 拼接）。
