# testNamePattern

- **类型：** `string | RegExp`
- **默认值：** `undefined`
- **CLI：** `-t=<value>`, `--testNamePattern=<value>`

按 `RegExp` 或正则模式字符串（通过 `new RegExp()` 编译）过滤测试的完整名称，不匹配的测试会被跳过。

完整名称由外层 `describe` 套件名称与测试用例名称拼接而成，默认以空格分隔（当模式中包含 `>` 时以 `' > '` 分隔）。由于套件名称也包含在匹配文本中，只要 `describe` 名称匹配，该套件内的所有测试都会执行。

当配置 `testNamePattern: 'bar'` 时：

```ts
// 跳过
test('test foo', () => {
  expect(true).toBe(true);
});

// 执行
test('test bar', () => {
  expect(true).toBe(true);
});

// 执行该套件内的所有测试
describe('bar', () => {
  it('should add two numbers correctly', () => {
    expect(1 + 1).toBe(2);
  });
});
```

如需排除名称匹配的测试，可以使用负向先行断言 `RegExp`：

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  testNamePattern: /^(?!.*bar).*$/,
});
```
