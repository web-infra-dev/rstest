# passWithNoTests

- **类型：** `boolean`
- **默认值：** `false`
- **CLI：** `--passWithNoTests`

标记测试通过当未找到测试用例时。

默认情况下，当未找到测试用例时，Rstest 会将测试标记为失败。你可以将 `passWithNoTests` 设置为 `true` 来允许测试在未找到测试用例时通过。

在非 watch 模式下，开启此选项后，如果没有找到测试文件，Rstest 只输出一行不带颜色强调的提示（`No test files found, exiting with code 0.`），不再输出查找详情。
