# reporters

- **类型：**

```ts
type ReporterItem =
  | Reporter
  | BuiltInReporterNames
  | (string & {})
  | ReporterWithOptions
  | [string]
  | [string, Record<string, unknown>];

type Reporters =
  Reporter | BuiltInReporterNames | (string & {}) | ReporterItem[];
```

- **默认值：**

```ts
process.env.GITHUB_ACTIONS === 'true'
  ? ['default', 'github-actions']
  : ['default'];
```

- **CLI：** `--reporters=<name> --reporters=<name1>`（同时兼容 `--reporter` 作为别名）

配置用于测试结果输出的报告器。

内置报告器名称包括 `default`、`dot`、`verbose`、`md`、`github-actions`、`junit`、`json` 和 `blob`。

:::info AI agent 环境
未显式配置 `reporters`（配置文件未设置 `reporters`，且 CLI 未传入 `--reporters`）时，Rstest 在 AI agent 环境中默认使用 `['md']`，将适合 AI agent 读取的 Markdown 输出到 stdout。
:::

### 报告器选项配置

在 `reporters` 数组中传入 `[reporterName, options]`，可为报告器传递配置选项：

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  reporters: [
    ['default', { summary: false }],
    ['github-actions', { summary: { maxCharsPerField: 1000 } }],
    ['junit', { outputPath: './test-results.xml' }],
  ],
});
```

### 内置报告器选项

完整类型定义见 [`packages/core/src/types/reporter.ts`](https://github.com/web-infra-dev/rstest/blob/main/packages/core/src/types/reporter.ts)。

- **`default`**：
  - `summary?: boolean`（默认值：`true`）—— 是否输出测试汇总信息。
  - `showProjectName?: boolean`（默认值：多 project 或多 browser 运行时为 `true`，否则为 `false`）—— 是否在测试文件标题中显示 project 名称。
- **`dot`**：支持 `summary`（默认值与 `default` 相同）。
- **`verbose`**：支持 `showProjectName`（默认值与 `default` 相同）。
- **`github-actions`**：
  - `annotations?: boolean`（默认值：`true`）—— 是否为失败测试输出 `::error` annotation。
  - `summary?: boolean | { maxCharsPerField?: number }`（默认值：`true`；`maxCharsPerField` 默认为 `400`）—— 是否将 Markdown 汇总写入 `GITHUB_STEP_SUMMARY`。
- **`junit`**：
  - `outputPath?: string` —— 将 JUnit XML 报告写入指定文件，而非输出到 stdout。
- **`json`**：
  - `outputPath?: string` —— 将 JSON 报告写入指定文件，而非输出到 stdout。
- **`blob`**：
  - `outputDir?: string`（默认值：`'.rstest-reports'`）—— blob 报告的输出目录。不支持在 watch mode 下使用。
- **`md`**：
  - `preset?: 'normal' | 'compact' | 'full'`（默认值：`'normal'`）—— 输出详略预设。
  - `header?: boolean | { env?: boolean }`（默认值：`{ env: true }`）—— 控制 frontmatter 中的运行时和环境信息。
  - `reproduction?: boolean | 'file' | 'file+name'`（默认值：`'file+name'`）—— 控制失败用例的复现命令。
  - `testLists?: 'auto' | 'always'`（默认值：`'auto'`）—— 控制何时输出 Passed / Skipped / Todo 列表。
  - `failures?: { max?: number }`（默认值：`{ max: 50 }`）—— 展开详情的最大失败数量。
  - `codeFrame?: boolean | { linesAbove?: number; linesBelow?: number }`（默认值：`{ linesAbove: 2, linesBelow: 2 }`）—— 代码片段上下文行数。
  - `stack?: number | false | 'full' | 'top'`（默认值：`'top'`）—— 每个错误输出的堆栈帧数量。
  - `candidateFiles?: boolean | { max?: number }`（默认值：`{ max: 5 }`）—— 从堆栈中提取的候选文件路径数量。
  - `console?: boolean | { maxLogsPerTestPath?: number; maxCharsPerEntry?: number }`（默认值：`{ maxLogsPerTestPath: 10, maxCharsPerEntry: 500 }`）—— 控制台日志输出限制。
  - `errors?: boolean | { unhandled?: boolean }`（默认值：`{ unhandled: true }`）—— 是否输出未捕获错误。

### 使用自定义报告器

传入模块标识符（或 `[模块标识符, 选项]`），该模块必须默认导出一个实现了 [`Reporter`](/api/javascript-api/reporter) 接口的类。Rstest 会以 `(options, { rootPath, config })` 实例化该类（未传选项时 `options` 为 `{}`）。在启用类型擦除的 Node.js 版本（22.18+ 或 24）上，`.ts` 和 `.mts` 模块可直接加载：

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  reporters: './custom-reporter.js',
});

// 传入选项：
export const configWithOptions = defineConfig({
  reporters: [['./custom-reporter.js', { outputPath: './report.json' }]],
});
```

也可以直接传入已创建并实现了 `Reporter` 接口的对象，但不能直接传入 Reporter 类。
