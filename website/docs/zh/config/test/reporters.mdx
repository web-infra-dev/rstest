# reporters

- **类型：**

```ts
type ReporterItem =
  | Reporter
  | BuiltInReporterNames
  | (string & {})
  | ReporterWithOptions
  | [string]
  | [string, Record<string, unknown>];

type Reporters =
  Reporter | BuiltInReporterNames | (string & {}) | ReporterItem[];
```

- **默认值：**

```ts
process.env.GITHUB_ACTIONS === 'true'
  ? ['default', 'github-actions']
  : ['default'];
```

- **CLI：** `--reporters=<name> --reporters=<name1>`（同时兼容 `--reporter` 作为别名）

配置用于测试结果输出的报告器。

内置报告器名称包括 `default`、`dot`、`verbose`、`md`、`github-actions`、`junit`、`json` 和 `blob`。

:::info AI agent 环境
未显式配置 `reporters`（配置文件未设置 `reporters`，且 CLI 未传入 `--reporters`）时，Rstest 在 AI agent 环境中默认使用 `['md']`，将适合 AI agent 读取的 Markdown 输出到 stdout。
:::

### 多个报告器

传入数组可同时启用多种报告器，例如同时输出控制台结果和 CI/CD 所需的报告文件：

<Tabs defaultValue='rstest.config.ts'>
  <Tab label="CLI">

```bash
npx rstest --reporters=default --reporters=junit
```

  </Tab>
  <Tab label="rstest.config.ts">

```ts
import { defineConfig } from '@rstest/core';

export default defineConfig({
  reporters: ['default', 'junit'],
});
```

  </Tab>
</Tabs>

### 报告器选项配置

在 `reporters` 数组中传入 `[reporterName, options]`，可为报告器传递配置选项。各内置报告器支持的选项见[报告器指南](/guide/basic/reporters)：

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  reporters: [
    ['default', { summary: false }],
    ['github-actions', { summary: { maxCharsPerField: 1000 } }],
    ['junit', { outputPath: './test-results.xml' }],
  ],
});
```

### 使用自定义报告器

传入模块标识符（或 `[模块标识符, 选项]`），该模块必须默认导出一个实现了 [`Reporter`](/api/javascript-api/reporter) 接口的类。Rstest 会以 `(options, { rootPath, config })` 实例化该类（未传选项时 `options` 为 `{}`）。在启用类型擦除的 Node.js 版本（22.18+ 或 24）上，`.ts` 和 `.mts` 模块可直接加载：

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  reporters: './custom-reporter.js',
});

// 传入选项：
export const configWithOptions = defineConfig({
  reporters: [['./custom-reporter.js', { outputPath: './report.json' }]],
});
```

也可以直接传入已创建并实现了 `Reporter` 接口的对象，但不能直接传入 Reporter 类。
