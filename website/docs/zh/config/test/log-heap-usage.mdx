# logHeapUsage

- **类型：** `boolean`
- **默认值：** `false`
- **CLI：** `--logHeapUsage`

在每个测试文件及展示的测试用例后输出 V8 `heapUsed` 内存用量，方便排查测试中的内存泄漏。

仅对 Node.js 测试生效；在 [Browser Mode](/config/test/browser) 下会被忽略并输出警告。

import { Tab, Tabs } from '@theme';

import { defineConfig } from '@rstest/core';

});

  </Tab>
</Tabs>

## 示例

启用 `logHeapUsage: true` 后，输出中会附带堆内存用量：

```bash
 ✓ test/index.test.ts (2) 11 MB heap used
 ✓ test/index1.test.ts (2) 11 MB heap used

 Test Files 2 passed
      Tests 2 passed | 2 skipped (4)
   Duration 233ms (build 175ms, tests 58ms)
```
