# resolveSnapshotPath

- **类型：** `(testPath: string, snapExtension: string) => string`
- **默认值：** `undefined`

自定义快照文件的存储路径。

这是一个全局配置项，只能在根配置中设置，无法在 [`projects`](/config/test/projects) 中按项目覆盖。

默认情况下，Rstest 会将快照文件保存在测试文件所在目录下的 `__snapshots__` 文件夹中。通过 `resolveSnapshotPath` 可以覆盖这一路径解析规则。

例如，将快照直接保存在测试文件同级目录：

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  resolveSnapshotPath: (testPath, snapshotExtension) =>
    testPath + snapshotExtension,
});
```
