# exclude

- **类型：** `string[] | { patterns: string[]; override?: boolean }`
- **默认值：** `['**/node_modules/**', '**/dist/**', '**/.{idea,git,cache,output,temp}/**']`
- **CLI：** `--exclude "**/fixtures/**"`

从测试文件发现阶段排除的 glob 模式列表，相对于 [root](/config/test/root) 解析。Rstest 还会自动排除临时构建输出目录（[`output.distPath.root`](/config/build/output#outputdistpath)，默认为 `dist/.rstest-temp`）。

## 示例

排除 `fixtures` 目录下的测试文件：

import { Tab, Tabs } from '@theme';

<Tabs defaultValue='rstest.config.ts'>
  <Tab label="CLI">
  ```bash
  npx rstest --exclude "**/fixtures/**"
  ```
  </Tab>
  <Tab label="rstest.config.ts">
```ts
import { defineConfig } from '@rstest/core';

export default defineConfig({
  exclude: ['**/fixtures/**'],
});
```
  </Tab>
</Tabs>

## 覆盖默认值

默认情况下，Rstest 会将自定义规则与默认规则合并。需要替换默认 `exclude` 规则时，将 `override` 设为 `true`：

```ts title='rstest.config.ts'
import { defineConfig } from '@rstest/core';

export default defineConfig({
  exclude: {
    patterns: ['**/node_modules/**'],
    override: true,
  },
});
```
