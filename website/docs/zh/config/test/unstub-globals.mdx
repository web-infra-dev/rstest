# unstubGlobals

- **类型：** `boolean`
- **默认值：** `false`
- **CLI：** `--unstubGlobals`

在每次测试执行前自动调用 [`rs.unstubAllGlobals()`](/api/runtime-api/rstest/utilities#rsunstuballglobals)，将通过 [`rs.stubGlobal()`](/api/runtime-api/rstest/utilities#rsstubglobal) 修改的所有 `globalThis` 属性恢复为原始描述符（或删除原本不存在的属性）。

import { Tab, Tabs } from '@theme';

<Tabs defaultValue='rstest.config.ts'>
  <Tab label="CLI">
  ```bash
  npx rstest --unstubGlobals
  ```
  </Tab>
  <Tab label="rstest.config.ts">
```ts
import { defineConfig } from '@rstest/core';

export default defineConfig({
  unstubGlobals: true,
});
```
  </Tab>
