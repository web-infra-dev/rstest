# includeTaskLocation

- **类型：** `boolean`
- **默认值：** `false`
- **CLI：** `--includeTaskLocation`

收集测试信息时，在传给 reporter 的任务对象（`TestCaseInfo`、`TestSuiteInfo`）和 `list` 命令输出中包含 `location`（`{ line, column }`）字段。

启用此选项会在测试收集阶段采集调用栈，对运行性能有轻微影响。

import { Tab, Tabs } from '@theme';

<Tabs defaultValue='rstest.config.ts'>
  <Tab label="CLI">
  ```bash
  npx rstest --includeTaskLocation
  ```
  </Tab>
  <Tab label="rstest.config.ts">
```ts
import { defineConfig } from '@rstest/core';

export default defineConfig({
  includeTaskLocation: true,
});
```
  </Tab>
</Tabs>

## 与 list 命令一起使用

在 `rstest list` 中传入 `--printLocation`，会自动启用 `includeTaskLocation` 并在每条测试旁输出 `file:line:column`：

```bash
npx rstest list --printLocation
```

## 示例输出

启用 `includeTaskLocation: true` 后，reporter 收到的 `TestCaseInfo` 和 `TestSuiteInfo` 对象会包含 `location` 字段：

```json
{
  "testId": "test-1",
  "name": "should calculate correct sum",
  "testPath": "/path/to/test.spec.ts",
  "location": {
    "line": 15,
    "column": 3
  }
}
```
