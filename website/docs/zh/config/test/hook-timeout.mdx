# hookTimeout

- **类型：** `number`
- **默认值：** `10_000`
- **CLI：** `--hookTimeout=10000`

生命周期 [Hook](/api/runtime-api/test-api/hooks)（`beforeAll`、`afterAll`、`beforeEach`、`afterEach`、`onTestFinished` 和 `onTestFailed`）的默认超时时间（毫秒）。设为 `0` 表示禁用超时。

Rstest 按以下优先级确定 Hook 超时时间：

1. 单个 [Hook](/api/runtime-api/test-api/hooks) 中传入的 `timeout` 参数
2. 测试文件中通过 [`rs.setConfig({ hookTimeout })`](/api/runtime-api/rstest/utilities#rssetconfig) 设置的超时时间
3. CLI 的 `--hookTimeout` 选项
4. 配置文件中的 `hookTimeout` 选项
5. 默认值 `10_000` 毫秒
