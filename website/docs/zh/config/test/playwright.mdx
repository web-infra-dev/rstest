# playwright

<ApiMeta addedVersion="0.12.0" />

- **类型：**

```ts
playwright?: Record<string, unknown>;
```

在当前 project 中设置 [@rstest/playwright](/guide/advanced/playwright) 提供的 `playwright` fixture 默认选项。

使用 `satisfies PlaywrightOptions` 可以从 integration package 获取具体的 Playwright 类型：

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';
import type { PlaywrightOptions } from '@rstest/playwright';

export default defineConfig({
  playwright: {
    launchOptions: {
      channel: 'chrome',
    },
    contextOptions: {
      viewport: { width: 1440, height: 900 },
    },
    trace: 'on-first-retry',
  } satisfies PlaywrightOptions,
});
```

只有支持 JSON 或 structured clone 的值才能通过 worker transport 传递。函数（例如 `launchOptions.logger`）、class instance，以及依赖当前测试或 retry 上下文动态计算的值不支持通过配置传入，这些场景请使用 `test.extend`。

## 使用 test.extend 覆盖

当某个测试或一组测试需要使用不同的 Playwright 选项时，可以通过 `test.extend` 覆盖 `playwright` fixture：

```ts title="tests/mobile.test.ts"
import { expect, test as base } from '@rstest/playwright';
import type { PlaywrightOptions } from '@rstest/playwright';

const test = base.extend({
  playwright: {
    browserName: 'chromium',
    contextOptions: {
      viewport: { width: 390, height: 844 },
    },
  } satisfies PlaywrightOptions,
});

test('uses the overridden viewport', async ({ page }) => {
  expect(page.viewportSize()).toEqual({ width: 390, height: 844 });
});
```

覆盖 `playwright` fixture 会替换当前 project 配置，而不是与其合并。如果需要保留 project 配置中的选项，请在覆盖值中一并写出。

这些选项会通过 `rs.getConfig().playwright` 提供给 Node worker。配置值必须可以通过 worker transport 传递。对于函数、class instance、依赖动态 retry 值的配置或测试级覆盖，请使用 `test.extend`。

测试通过 `test.extend` 覆盖 `playwright` fixture 时，fixture 覆盖值的优先级高于当前 project 配置。
