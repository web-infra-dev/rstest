# Mock instance

`MockInstance` 是所有 mock 和 spy 实例的类型，提供用于控制和检查 mock 状态的方法与属性。

## getMockName

- **类型：** `() => string`

返回通过 `.mockName()` 设置的 mock 名称，未设置时返回默认名称（`'rstest.fn()'` 或被 spy 的方法名）。

```ts
const fn = rs.fn();
fn.mockName('myMock');
expect(fn.getMockName()).toBe('myMock');
```

## mockName

- **类型：** `(name: string) => this`

设置此 mock 实例的名称，便于在断言报错和调试输出中区分。

```ts
const fn = rs.fn();
fn.mockName('logger');
```

## mockClear

- **类型：** `() => this`

清除所有调用记录（`calls`、`instances`、`contexts`、`invocationCallOrder`、`lastCall`、`results` 和 `settledResults`）。

```ts
const fn = rs.fn();
fn(1);
fn.mockClear();
expect(fn.mock.calls.length).toBe(0);
```

## mockReset

- **类型：** `() => this`

调用 `mockClear()` 并将实现重置为初始状态。

```ts
const fn = rs.fn().mockImplementation(() => 1);
fn.mockReset();
// 实现已被重置
```

## mockRestore

- **类型：** `() => void`

调用 `mockReset()`，在被 spy 的对象上恢复原始属性描述符，并重置 mock 名称。

```ts
const obj = { foo: () => 1 };
const spy = rs.spyOn(obj, 'foo');
spy.mockRestore();
```

## Symbol.dispose

<ApiMeta addedVersion="0.10.2" />

- **类型：** `() => void`

当 mock 离开 `using` 作用域时调用 `mockRestore()`。

```ts
const obj = { foo: () => 1 };

{
  using spy = rs.spyOn(obj, 'foo').mockImplementation(() => 2);
  expect(obj.foo()).toBe(2);
}

expect(obj.foo()).toBe(1);
```

## getMockImplementation

- **类型：** `() => NormalizedProcedure<T> | undefined`

返回当前的 mock 实现函数（如有），其中 `NormalizedProcedure<T>` 为 `(...args: Parameters<T>) => ReturnType<T>`。

```ts
const fn = rs.fn(() => 123);
const impl = fn.getMockImplementation();
```

## mockImplementation

- **类型：** `(fn: NormalizedProcedure<T>) => this`

为 mock 设置实现函数。

```ts
const fn = rs.fn();
fn.mockImplementation((a: number, b: number) => a + b);
```

## mockImplementationOnce

- **类型：** `(fn: NormalizedProcedure<T>) => this`

仅为下一次调用设置实现函数。

```ts
const fn = rs.fn();
fn.mockImplementationOnce(() => 1);
fn(); // 返回 1
fn(); // 返回 undefined
```

## withImplementation

- **类型：** `<T2>(fn: NormalizedProcedure<T>, callback: () => T2) => T2 extends Promise<unknown> ? Promise<this> : this`

在 `callback` 执行期间临时替换 mock 的实现函数，执行完毕后恢复原实现（包括之前排队的 `mockImplementationOnce`）。返回该 mock 实例；当 `callback` 返回 promise 时，返回 resolve 为该实例的 promise。

```ts
const fn = rs.fn(() => 1);
fn.withImplementation(
  () => 2,
  () => {
    expect(fn()).toBe(2);
  },
);
expect(fn()).toBe(1);
```

## mockReturnThis

- **类型：** `() => this`

使 mock 在调用时返回 `this`。

```ts
const fn = rs.fn();
fn.mockReturnThis();
const obj = { fn };
expect(obj.fn()).toBe(obj);
```

## mockReturnValue

- **类型：** `(value: ReturnType<T>) => this`

使 mock 始终返回指定值 `value`。

```ts
const fn = rs.fn();
fn.mockReturnValue(42);
expect(fn()).toBe(42);
```

## mockReturnValueOnce

- **类型：** `(value: ReturnType<T>) => this`

使 mock 仅在下一次调用时返回指定值 `value`。

```ts
const fn = rs.fn();
fn.mockReturnValueOnce(1);
expect(fn()).toBe(1);
expect(fn()).toBe(undefined);
```

## mockThrow

<ApiMeta addedVersion="0.11.4" />

- **类型：** `(value: unknown) => this`

使 mock 在每次调用时抛出 `value`。

```ts
const fn = rs.fn().mockThrow(new Error('fail'));
expect(() => fn()).toThrow('fail');
```

## mockThrowOnce

<ApiMeta addedVersion="0.11.4" />

- **类型：** `(value: unknown) => this`

使 mock 仅在下一次调用时抛出 `value`。

```ts
const fn = rs.fn(() => 'ok').mockThrowOnce(new Error('fail'));
expect(() => fn()).toThrow('fail');
expect(fn()).toBe('ok');
```

## mockResolvedValue

- **类型：** `(value: Awaited<ReturnType<T>>) => this`

使 mock 返回一个 resolve 为 `value` 的 Promise。

```ts
const fn = rs.fn();
fn.mockResolvedValue(123);
await expect(fn()).resolves.toBe(123);
```

## mockResolvedValueOnce

- **类型：** `(value: Awaited<ReturnType<T>>) => this`

使 mock 仅在下一次调用时返回一个 resolve 为 `value` 的 Promise。

```ts
const fn = rs.fn();
fn.mockResolvedValueOnce(1);
await expect(fn()).resolves.toBe(1);
await expect(fn()).resolves.toBe(undefined);
```

## mockRejectedValue

- **类型：** `(error: unknown) => this`

使 mock 返回一个 reject 为 `error` 的 Promise。

```ts
const fn = rs.fn();
fn.mockRejectedValue(new Error('fail'));
await expect(fn()).rejects.toThrow('fail');
```

## mockRejectedValueOnce

- **类型：** `(error: unknown) => this`

使 mock 仅在下一次调用时返回一个 reject 为 `error` 的 Promise。

```ts
const fn = rs.fn();
fn.mockRejectedValueOnce(new Error('fail'));
await expect(fn()).rejects.toThrow('fail');
await expect(fn()).resolves.toBe(undefined);
```

## mock

保存 mock 的调用状态，包括每次调用的参数、返回值、实例和 `this` 上下文。

```ts
const fn = rs.fn((a: number, b: number) => a + b);
fn(1, 2);
expect(fn.mock.calls[0]).toEqual([1, 2]);
```

### mock.calls

- **类型：** `Parameters<T>[]`

包含每次调用 mock 函数时传入参数的数组。

```ts
const fn = rs.fn((a: number, b: number) => a + b);
fn(1, 2);
fn(3, 4);
console.log(fn.mock.calls); // [[1, 2], [3, 4]]
```

### mock.instances

- **类型：** `ReturnType<T>[]`

包含将 mock 作为构造函数调用时创建的所有实例的数组。

```ts
const Fn = rs.fn(function (this: { x: number }) {
  this.x = 1;
});
const a = new Fn();
const b = new Fn();
console.log(Fn.mock.instances); // [a, b]
```

### mock.contexts

- **类型：** `ThisParameterType<T>[]`

包含每次调用 mock 函数时的 `this` 上下文的数组。

```ts
const fn = rs.fn();
const context = {};

fn.apply(context);
fn.call(context);

expect(fn.mock.contexts[0]).toBe(context);
expect(fn.mock.contexts[1]).toBe(context);
```

### mock.invocationCallOrder

- **类型：** `number[]`

表示 mock 调用顺序的数字数组（在所有 mock 间共享），索引从 `1` 开始。

```ts
const fn1 = rs.fn();
const fn2 = rs.fn();
fn1();
fn2();
fn1();
console.log(fn1.mock.invocationCallOrder); // [1, 3]
console.log(fn2.mock.invocationCallOrder); // [2]
```

### mock.lastCall

- **类型：** `Parameters<T> | undefined`

mock 函数最后一次调用的参数；若尚未被调用，则为 `undefined`。

```ts
const fn = rs.fn();
fn(1, 2);
fn(3, 4);
console.log(fn.mock.lastCall); // [3, 4]
```

### mock.results

- **类型：** `MockResult<ReturnType<T>>[]`

包含每次调用同步结果的数组（`{ type: 'return', value }`、`{ type: 'throw', value }` 或 `{ type: 'incomplete', value: undefined }`）。

```ts
const fn = rs.fn((a: number) => {
  if (a < 0) {
    throw new Error('fail');
  }
  return a * 2;
});
fn(2);
try {
  fn(-1);
} catch {}
console.log(fn.mock.results);
// [{ type: 'return', value: 4 }, { type: 'throw', value: Error }]
```

### mock.settledResults

- **类型：** `MockSettledResult<Awaited<ReturnType<T>>>[]`

对于返回值为 Promise 的调用，记录其最终 settled 结果（`{ type: 'fulfilled', value }` 或 `{ type: 'rejected', value }`）的数组。

```ts
const fn = rs.fn(async (x: number) => {
  if (x > 0) return x;
  throw new Error('fail');
});
await fn(1);
try {
  await fn(0);
} catch {}
console.log(fn.mock.settledResults);
// [{ type: 'fulfilled', value: 1 }, { type: 'rejected', value: Error }]
```
