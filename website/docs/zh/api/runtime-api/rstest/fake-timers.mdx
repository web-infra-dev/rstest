# Fake timers

Fake timers 会替换全局定时器函数与 `Date`，让测试无需等待真实超时即可控制时间推进，底层基于 [@sinonjs/fake-timers](https://github.com/sinonjs/fake-timers)。

## rs.useFakeTimers

- **别名：** `rstest.useFakeTimers`
- **类型：** `(config?: FakeTimerInstallOpts) => RstestUtilities & Disposable`

启用 fake timers，接管 `setTimeout`、`setInterval`、`Date`、`performance` 等定时器 API（默认不接管 `Intl`、`nextTick` 和 `queueMicrotask`）。

```ts
rs.useFakeTimers();
```

传入 `config` 可将配置透传给 `@sinonjs/fake-timers`：例如用 `toFake` / `toNotFake` 指定要接管的定时器 API，用 `now` 设置初始模拟时间，或用 `shouldAdvanceTime` / `advanceTimeDelta` 开启自动推进。

- **`using` 语法**

<ApiMeta addedVersion="0.10.3" />

`rs.useFakeTimers()` 返回一个 `Disposable`，在 `using` 代码块退出时自动恢复真实定时器（`using` 语法要求声明变量，例如 `_timers`）：

```ts
{
  using _timers = rs.useFakeTimers();
  // Fake timers 在此代码块中生效。
}

// 真实定时器已恢复。
```

## rs.useRealTimers

- **别名：** `rstest.useRealTimers`
- **类型：** `() => RstestUtilities`

恢复原生定时器函数与 `Date`，关闭 fake timers。

```ts
rs.useRealTimers();
```

## rs.isFakeTimers

- **别名：** `rstest.isFakeTimers`
- **类型：** `() => boolean`

当前是否启用了 fake timers。

```ts
if (rs.isFakeTimers()) {
  // Fake timers 已启用
}
```

## rs.setSystemTime

- **别名：** `rstest.setSystemTime`
- **类型：** `(now?: number | Date | { epochMilliseconds: number }) => RstestUtilities`

设置当前系统时间。

启用 fake timers 时，仅修改模拟时钟（影响 `Date`，不改变 `performance.now()`），不会触发任何定时器；未启用 fake timers 时，仅 mock `Date`，因此无需先调用 [`rs.useFakeTimers`](#rsusefaketimers) 即可固定当前时间。

`now` 也支持带有 `epochMilliseconds` 的 Temporal 对象（如 `Temporal.Instant` 或 `Temporal.ZonedDateTime`）。

```ts
rs.setSystemTime(new Date('2020-01-01T00:00:00Z'));

expect(new Date().toISOString()).toBe('2020-01-01T00:00:00.000Z');

rs.useRealTimers();
```

## rs.getRealSystemTime

- **别名：** `rstest.getRealSystemTime`
- **类型：** `() => number`

返回真实的系统毫秒时间戳，即使已启用 fake timers 也不受影响。

```ts
const realTime = rs.getRealSystemTime();
```

## rs.getRealTimers

<ApiMeta addedVersion="0.11.1" />

- **别名：** `rstest.getRealTimers`
- **类型：** `() => { setTimeout: typeof globalThis.setTimeout; clearTimeout: typeof globalThis.clearTimeout; setImmediate?: typeof globalThis.setImmediate }`

返回 Rstest 捕获的真实定时器函数，即使已启用 fake timers 仍可使用真实定时器。

```ts
const { setTimeout, clearTimeout } = rs.getRealTimers();

const timeout = setTimeout(() => {
  // 使用真实时间运行。
}, 1000);

clearTimeout(timeout);
```

## rs.runAllTicks

- **别名：** `rstest.runAllTicks`
- **类型：** `() => RstestUtilities`

执行所有由被模拟的微任务 API（如通过 `toFake` 启用的 `process.nextTick` 和 `queueMicrotask`）排队的微任务。

## rs.runAllTimers

- **别名：** `rstest.runAllTimers`
- **类型：** `() => RstestUtilities`

执行所有待运行的定时器（包括 timeout 和 interval），包含执行期间新调度的定时器。

## rs.runAllTimersAsync

- **别名：** `rstest.runAllTimersAsync`
- **类型：** `() => Promise<RstestUtilities>`

异步执行所有待运行的定时器，并在每个定时器回调之间刷新微任务。

## rs.runOnlyPendingTimers

- **别名：** `rstest.runOnlyPendingTimers`
- **类型：** `() => RstestUtilities`

仅执行当前待运行的定时器；执行期间新调度的定时器不会运行。

## rs.runOnlyPendingTimersAsync

- **别名：** `rstest.runOnlyPendingTimersAsync`
- **类型：** `() => Promise<RstestUtilities>`

异步执行当前待运行的定时器，并在每个定时器回调之间刷新微任务。

## rs.advanceTimersByTime

- **别名：** `rstest.advanceTimersByTime`
- **类型：** `(ms: number | string | Temporal.Duration) => RstestUtilities`

将 fake timers 快进指定时长，并执行该时间窗口内调度的所有定时器。

字符串时长遵循 `@sinonjs/fake-timers` 格式（例如 `'00:10'` 表示 10 秒）。

## rs.advanceTimersByTimeAsync

- **别名：** `rstest.advanceTimersByTimeAsync`
- **类型：** `(ms: number | string | Temporal.Duration) => Promise<RstestUtilities>`

异步快进 fake timers 指定时长，并在每个定时器回调之间刷新微任务。

## rs.advanceTimersToNextTimer

- **别名：** `rstest.advanceTimersToNextTimer`
- **类型：** `(steps?: number) => RstestUtilities`

将 fake timers 推进到下一个已调度的定时器，最多重复执行 `steps` 次（默认为 `1`）。

## rs.advanceTimersToNextTimerAsync

- **别名：** `rstest.advanceTimersToNextTimerAsync`
- **类型：** `(steps?: number) => Promise<RstestUtilities>`

异步将 fake timers 推进到下一个已调度的定时器，最多重复执行 `steps` 次（默认为 `1`）。

## rs.advanceTimersToNextFrame

- **别名：** `rstest.advanceTimersToNextFrame`
- **类型：** `() => RstestUtilities`

将 fake timers 推进到下一个动画帧。

## rs.jumpTimersByTime

<ApiMeta addedVersion="0.11.0" />

- **别名：** `rstest.jumpTimersByTime`
- **类型：** `(ms: number | string | Temporal.Duration) => RstestUtilities`

将模拟时钟直接跳过指定时长，每个受影响的定时器回调最多只触发一次（跳过中间的 interval tick，类似于模拟进程休眠后唤醒）。

```ts
rs.useFakeTimers({ now: 0 });

const cb = rs.fn();
setInterval(cb, 1000);

rs.jumpTimersByTime(5000);

expect(cb).toHaveBeenCalledTimes(1);
```

## rs.setTickMode

<ApiMeta addedVersion="0.11.0" />

- **别名：** `rstest.setTickMode`
- **类型：** `(mode: { mode: 'manual' | 'nextAsync' } | { mode: 'interval'; delta?: number }) => RstestUtilities`

配置 fake timers 自动推进时间的方式：

- `{ mode: 'manual' }`：仅在显式调用 `rs.advanceTimersByTime()` 等 API 时推进时间。
- `{ mode: 'nextAsync' }`：持续推进到下一个已调度的定时器，并在定时器之间让 Promise 回调运行。
- `{ mode: 'interval', delta?: number }`：按固定间隔推进模拟时间（等价于 `shouldAdvanceTime` / `advanceTimeDelta`）。

```ts
rs.useFakeTimers();
rs.setTickMode({ mode: 'nextAsync' });

await new Promise((resolve) => setTimeout(resolve, 1000));
```

## rs.getTimerCount

- **别名：** `rstest.getTimerCount`
- **类型：** `() => number`

返回当前尚未执行的 fake timers 数量。

```ts
const count = rs.getTimerCount();
```

## rs.clearAllTimers

- **别名：** `rstest.clearAllTimers`
- **类型：** `() => RstestUtilities`

移除所有已调度但尚未执行的 fake timers。

```ts
rs.clearAllTimers();
```
