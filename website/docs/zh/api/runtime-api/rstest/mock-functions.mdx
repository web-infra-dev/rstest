# Mock functions

Rstest 基于 [tinyspy](https://github.com/tinylibs/tinyspy) 提供用于创建 mock 函数、spy 对象方法和深度 mock 对象的工具方法。

## rs.fn

- **别名：** `rstest.fn`
- **类型：**

```ts
type FunctionLike = (...args: any) => any;

export interface Mock<
  T extends FunctionLike = FunctionLike,
> extends MockInstance<T> {
  new (...args: Parameters<T>): ReturnType<T>;
  (...args: Parameters<T>): ReturnType<T>;
}

export type MockFn = <T extends FunctionLike = FunctionLike>(fn?: T) => Mock<T>;
```

创建一个 mock 函数，可传入可选的默认实现 `fn`。

为可调用 mock 函数标注类型时，请参考 [`Mock`](/api/javascript-api/types#mock) 类型。

```ts
const sayHi = rs.fn((name: string) => `hi ${name}`);

const res = sayHi('bob');

expect(res).toBe('hi bob');
expect(sayHi).toHaveBeenCalledTimes(1);
```

## rs.spyOn

- **别名：** `rstest.spyOn`
- **类型：**

```ts
export type SpyFn = <T extends Record<string, any>, K extends keyof T>(
  obj: T,
  methodName: K,
  accessType?: 'get' | 'set',
) => MockInstance<T[K]>;
```

为对象的方法或属性访问器（通过 `accessType` 指定 `'get'` 或 `'set'`）创建 spy，并在被覆盖前保持原实现。

关于 spy 返回的控制 API，请参考 [`MockInstance`](/api/javascript-api/types#mockinstance) 类型。

```ts
const sayHi = () => 'hi';
const hi = {
  sayHi,
};

const spy = rs.spyOn(hi, 'sayHi');

expect(hi.sayHi()).toBe('hi');
expect(spy).toHaveBeenCalled();
```

对同一个方法多次调用 `rs.spyOn` 时，会复用已有的 spy 实例，而不会重复包装：

```ts
const hi = {
  sayHi: () => 'hi',
};
rs.spyOn(hi, 'sayHi').mockImplementation(() => 'hello');

expect(hi.sayHi()).toBe('hello');
// 返回与首次调用相同的 spy 实例
expect(rs.spyOn(hi, 'sayHi')).toHaveBeenCalled();
```

:::note 对 re-export 或第三方模块的导出进行 spy

`rs.spyOn` 可以作用于当前导入模块中直接定义的导出，但对从其他模块 **re-export**（`export * from '...'`）或原生/第三方 ES 模块暴露的只读导出不会生效。

这种情况下，请改用 [`{ spy: true }`](/api/runtime-api/rstest/mock-modules#with-spy-true-option) 来 mock 该模块，在保留原实现的同时为每个导出装上 spy：

```ts
rs.mock('pkg', { spy: true });
```

:::

## rs.isMockFunction

- **别名：** `rstest.isMockFunction`
- **类型：** `(fn: any) => fn is MockInstance`

判断 `fn` 是否为 mock 函数，并在 TypeScript 中将其类型收窄为 [`MockInstance`](./mock-instance)。

## rs.mockObject

- **别名：** `rstest.mockObject`
- **类型：**

```ts
type MockObject = <T>(
  object: T,
  options?: { spy?: boolean },
) => MaybeMockedDeep<T>;
```

创建对象的深度 mock。函数会被替换为 mock 函数（对普通对象递归处理），原始值和 `Date`、`RegExp`、`Map` 等内置对象会保持不变。

### 基本用法

```ts
const original = {
  method() {
    return 42;
  },
  nested: {
    getValue() {
      return 'real';
    },
  },
  prop: 'foo',
};

const mocked = rs.mockObject(original);

// 方法会被替换为 mock 函数，默认返回 undefined
expect(rs.isMockFunction(mocked.method)).toBe(true);
expect(mocked.method()).toBeUndefined();
expect(mocked.nested.getValue()).toBeUndefined();

// 可通过标准 Mock 方法配置返回值
mocked.method.mockReturnValue(100);
expect(mocked.method()).toBe(100);

// 原始值保持不变
expect(mocked.prop).toBe('foo');
```

### Spy 模式

传入 `{ spy: true }` 作为第二个参数时，会保留原始实现并追踪调用：

```ts
const original = {
  add: (a: number, b: number) => a + b,
};

const spied = rs.mockObject(original, { spy: true });

expect(spied.add(1, 2)).toBe(3);
expect(spied.add).toHaveBeenCalledWith(1, 2);
expect(spied.add.mock.results[0]).toEqual({ type: 'return', value: 3 });
```

### 数组

默认情况下，数组会被替换为空数组。传入 `{ spy: true }` 时会保留数组元素（同时对其中的函数和普通对象装上 spy）：

```ts
const mocked = rs.mockObject({ array: [1, 2, 3] });
expect(mocked.array).toEqual([]);

const spied = rs.mockObject({ array: [1, 2, 3] }, { spy: true });
expect(spied.array).toEqual([1, 2, 3]);
```

### Mock 类

传入类构造函数即可 mock 该类。不传 `{ spy: true }` 时，`rs.mockObject(Class)` 只返回一个普通 mock 函数（`new` 返回 `undefined`，不会 mock 原型方法）。使用 `{ spy: true }` 时，实例会保留原方法并附加 spy：

```ts
class UserService {
  getUser() {
    return { id: 1, name: 'Alice' };
  }
}

const MockedService = rs.mockObject(UserService, { spy: true });
const instance = new MockedService();

expect(instance.getUser()).toEqual({ id: 1, name: 'Alice' });

rs.mocked(instance.getUser).mockImplementation(() => ({ id: 2, name: 'Bob' }));
expect(instance.getUser()).toEqual({ id: 2, name: 'Bob' });
```

## rs.mocked

- **别名：** `rstest.mocked`
- **类型：**

```ts
type MockedFn = (<T>(item: T, deep?: false) => Mocked<T>) &
  (<T>(item: T, deep: true) => MaybeMockedDeep<T>) &
  (<T>(item: T, options: { partial?: false; deep?: false }) => Mocked<T>) &
  (<T>(
    item: T,
    options: { partial?: false; deep: true },
  ) => MaybeMockedDeep<T>) &
  (<T>(
    item: T,
    options: { partial: true; deep?: false },
  ) => MaybePartiallyMocked<T>) &
  (<T>(
    item: T,
    options: { partial: true; deep: true },
  ) => MaybePartiallyMockedDeep<T>);
```

TypeScript 类型辅助函数，运行时原样返回 `item`，仅在类型层面将其方法标记为 mock。传入 `true` 或 `{ deep: true }` 会递归应用 mock 类型；传入 `{ partial: true }` 则使用部分 mock 类型。

为 mock 对象或模块标注类型时，请参考 [`Mocked`](/api/javascript-api/types#mocked) 类型。

```ts
import { myModule } from './myModule';

rs.mock('./myModule', { spy: true });

// TypeScript 现在知道 myModule.method 是一个 MockInstance
const mockedModule = rs.mocked(myModule);

mockedModule.method.mockReturnValue('mocked');
```

## rs.clearAllMocks

- **别名：** `rstest.clearAllMocks`
- **类型：** `() => RstestUtilities`

对所有 mock 调用 `.mockClear()`，清除所有调用记录（`mock.calls`、`mock.instances`、`mock.contexts`、`mock.invocationCallOrder`、`mock.lastCall`、`mock.results` 和 `mock.settledResults`）。

## rs.resetAllMocks

- **别名：** `rstest.resetAllMocks`
- **类型：** `() => RstestUtilities`

对所有 mock 调用 `.mockReset()`，清除所有调用记录，并将每个 mock 的实现重置为初始状态。

## rs.restoreAllMocks

- **别名：** `rstest.restoreAllMocks`
- **类型：** `() => RstestUtilities`

恢复通过 `rs.spyOn()` 替换的原始属性描述符。不会清除调用记录或重置 mock 实现，也不会影响通过 `rs.fn()` 创建的独立 mock。
