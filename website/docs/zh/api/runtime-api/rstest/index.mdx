# Rstest utility

Rstest 通过 `rs` 工具对象提供用于 mock、fake timers 和环境模拟的工具函数。

从 `@rstest/core` 直接导入 `rs`：

```ts
import { rs } from '@rstest/core';

const fn = rs.fn();
fn.mockResolvedValue('foo');
```

也可以使用别名 `rstest`：

```ts
import { rstest } from '@rstest/core';

const fn = rstest.fn();
fn.mockResolvedValue('foo');
```

启用 [globals](/config/test/globals) 配置后，无需导入即可全局访问 `rs` 和 `rstest`。
