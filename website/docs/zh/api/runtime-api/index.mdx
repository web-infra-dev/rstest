Rstest 提供用于编写测试、Mock、浏览器自动化以及读取测试运行状态的环境 API：

- [Test API](/api/runtime-api/test-api/expect)：`expect`、`assert`、`test`、`describe` 与生命周期 hooks。
- [Browser Mode](/api/runtime-api/browser-mode/)：`page`、`Locator`、键盘操作、`expect.element` 与 React 测试工具。
- [Rstest utility](/api/runtime-api/rstest/)：用于 mock、fake timers、环境存根、运行时配置与轮询的 `rs` / `rstest` 工具集。
- [环境变量](/api/runtime-api/environment-variables)：Rstest 注入或读取的环境变量。
