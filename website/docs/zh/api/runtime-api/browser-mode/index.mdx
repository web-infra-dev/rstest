# Browser mode

[@rstest/browser](https://github.com/web-infra-dev/rstest/tree/main/packages/browser) 提供 Browser Mode 运行时 API，支持 Playwright 风格的 `Locator` 工作流。

## 导出 API

- [`page`](/api/runtime-api/browser-mode/locator#page)：`BrowserPage` 入口，提供元素查询、DOM 转换、[`keyboard`](/api/runtime-api/browser-mode/keyboard) 键盘输入和 [`viewport`](/api/runtime-api/browser-mode/locator#pageviewport) 视口调整
- [`Locator`](/api/runtime-api/browser-mode/locator)：用于链式查询与交互的核心类
- [`BrowserPage`](/api/runtime-api/browser-mode/locator#browserpage)：`page` 的类型定义
- [`setTestIdAttribute`](/api/runtime-api/browser-mode/locator#settestidattribute)：配置 `getByTestId()` 使用的属性名

`@rstest/browser` 同时导出 `LocatorClickOptions`、`LocatorGetByRoleOptions`、`BrowserKeyboard` 等选项和辅助类型。

## 断言 API

在 Browser Mode 测试中导入 `@rstest/browser` 后，`@rstest/core` 的 `expect` 会自动扩展以下能力：

- [`expect.element(target)`](/api/runtime-api/browser-mode/assertion)：对 `Locator` 或 DOM `Element` 执行自动重试的 DOM 断言
- [`toMatchScreenshot()`](/api/runtime-api/browser-mode/assertion#toMatchScreenshot)：对 `Locator` 或 `page` 执行视觉截图对比

## 示例：查询、交互与断言

```ts title="browser-example.test.ts"
import { page } from '@rstest/browser';
import { expect, test } from '@rstest/core';

test('submits form', async () => {
  await page.getByLabel('Email').fill('dev@rstest.rs');
  await page.getByRole('button', { name: 'Submit' }).click();
  await expect.element(page.getByText('Done')).toBeVisible();
});
```
