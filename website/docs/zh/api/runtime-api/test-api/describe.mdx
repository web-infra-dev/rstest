# Describe

`describe` 用于将测试用例或嵌套套件组织为一个测试套件。

## describe

- **类型：**

```ts
(name: string | Function, fn?: () => void | Promise<void>, timeout?: number): void;
(name: string | Function, options: TestOptions, fn?: () => void | Promise<void>): void;
```

定义一个测试套件，可包含多个测试用例或嵌套的 `describe`。如果 `fn` 是异步函数，Rstest 会在收集阶段等待它完成，再执行内部声明的测试。

```ts
import { describe, expect, test } from '@rstest/core';

describe('math', () => {
  test('add', () => {
    expect(1 + 2).toBe(3);
  });
});
```

```ts
describe('async setup', async () => {
  const data = await loadFixtureData();

  test('uses collected data', () => {
    expect(data).toBeDefined();
  });
});
```

<ApiMeta addedVersion="0.12.3" />

可以直接将函数作为 `name` 传入。Rstest 会读取它的 `name` 属性而不会调用该函数（匿名函数显示为 `<anonymous>`）。`describe.each` 和 `describe.for` 也支持此写法。

```ts
function add(a: number, b: number) {
  return a + b;
}

describe(add, () => {
  test('adds numbers', () => {
    expect(add(1, 2)).toBe(3);
  });
});
```

### TestOptions

<ApiMeta addedVersion="0.11.0" />

将 [`TestOptions`](/api/runtime-api/test-api/test#testoptions) 对象作为**第二个参数**（位于套件函数之前）传入，为子套件和测试用例设置可继承的默认值（`timeout`、`retry`、`repeats` 与 `meta`）。将数字作为**最后一个参数**传入等价于 `{ timeout: n }`。

- 测试级别的选项始终优先于套件级别的值。
- 嵌套的 `describe` 会继承父级选项，由最内层的值覆盖外层。
- 若测试和外层套件均未设置 `timeout`，则回退到 [`test.testTimeout`](/config/test/test-timeout)。
- `meta` <ApiMeta sup addedVersion="0.11.1" /> 会从父套件向子套件或测试合并：子级顶层同名字段覆盖父级字段，继承值会为每个子级创建独立副本。

```ts
describe('parent', { retry: 2, timeout: 100 }, () => {
  test('a', () => {
    /* retry: 2, timeout: 100 */
  });

  describe('child', { timeout: 200 }, () => {
    test('b', () => {
      /* retry: 2（继承），timeout: 200（最近一层优先） */
    });

    test('c', { retry: 0 }, () => {
      /* retry: 0（自身值优先），timeout: 200 */
    });
  });
});
```

```ts
describe(
  'mutation run',
  { meta: { runner: 'stryker', shared: 'suite' } },
  () => {
    test('inherits suite metadata', ({ task }) => {
      // task.meta 为 { runner: 'stryker', shared: 'suite' }
    });

    test(
      'overrides suite metadata',
      { meta: { shared: 'test' } },
      ({ task }) => {
        // task.meta 为 { runner: 'stryker', shared: 'test' }
      },
    );
  },
);
```

## describe.only

只运行当前文件中标记了 `only` 的 `describe` 块。

```ts
describe.only('只运行这个套件', () => {
  // ...
});
```

## describe.skip

将 `describe` 块中的所有测试标记为跳过。

```ts
describe.skip('跳过这个套件', () => {
  // ...
});
```

套件回调本身仍会在收集阶段执行，以便 Rstest 收集其中的跳过测试并追踪快照，但内部的测试体不会运行：

```ts
describe.skip('a', () => {
  console.log('收集阶段会执行');
  test('b', () => {
    console.log('不会执行');
    expect(0).toBe(0);
  });
});
```

## describe.todo

将 `describe` 块标记为待办。

```ts
describe.todo('should implement this suite');
```

## describe.each

- **类型：**

```ts
type DescribeCall<Fn> = {
  (name: string | Function, fn?: Fn, timeout?: number): void;
  (name: string | Function, options: TestOptions, fn?: Fn): void;
};

// 对象行：整行作为单个参数传入
describe.each<T extends Record<string, unknown>>(
  cases: readonly T[],
): DescribeCall<(param: T) => void | Promise<void>>;
// 元组或数组行：每一行都是数组时，展开为多个参数
describe.each<T extends readonly [unknown, ...unknown[]]>(
  cases: readonly T[],
): DescribeCall<(...args: [...T]) => void | Promise<void>>;
describe.each<T extends readonly unknown[]>(
  cases: readonly T[],
): DescribeCall<(...args: [...T]) => void | Promise<void>>;
// 混合或基本类型行：整行作为单个参数传入
describe.each<T>(
  cases: readonly T[],
): DescribeCall<(param: T) => void | Promise<void>>;
// 标签模板字面量表格
describe.each<T extends Record<string, unknown>>(
  strings: TemplateStringsArray,
  ...expressions: unknown[]
): DescribeCall<(param: T) => void | Promise<void>>;
```

为 `cases` 或标签模板表格中的每一项生成一个 `describe` 块。第二个参数同样可选接受 [`TestOptions`](#testoptions)，并作用于生成的每个套件。

```ts
describe.each([
  { a: 1, b: 2 },
  { a: 2, b: 3 },
])('math $a + $b', ({ a, b }) => {
  test('add', () => {
    // ...
  });
});
```

只有当每一行都是数组时，行元素才会展开为 `fn` 的多个参数；只要存在非数组行，每一行都会整体作为单个参数传入。

使用标签模板字面量时，可传入显式泛型参数为行属性提供类型推导：

```ts
describe.each<{ a: number; b: number; expected: number }>`
  a    | b    | expected
  ${1} | ${2} | ${3}
  ${2} | ${3} | ${5}
`('$a + $b = $expected', ({ a, b, expected }) => {
  test('add', () => {
    expect(a + b).toBe(expected);
  });
});
```

## describe.for

- **类型：**

```ts
type DescribeCall<Fn> = {
  (name: string | Function, fn?: Fn, timeout?: number): void;
  (name: string | Function, options: TestOptions, fn?: Fn): void;
};

describe.for<T>(
  cases: readonly T[],
): DescribeCall<(param: T) => void | Promise<void>>;
describe.for<T extends Record<string, unknown>>(
  strings: TemplateStringsArray,
  ...expressions: unknown[]
): DescribeCall<(param: T) => void | Promise<void>>;
```

`describe.each` 的替代方法，始终将每条用例整体作为单个 `param` 参数传入，不会展开数组行。第二个参数同样可选接受 [`TestOptions`](#testoptions)。

```ts
describe.for([
  [1, 2],
  [2, 3],
])('math %i + %i', ([a, b]) => {
  test('add', () => {
    // ...
  });
});
```

同样支持标签模板字面量以及可选的显式泛型参数：

```ts
describe.for<{ a: number; b: number; expected: number }>`
  a    | b    | expected
  ${1} | ${2} | ${3}
  ${2} | ${3} | ${5}
`('$a + $b = $expected', ({ a, b, expected }) => {
  test('add', () => {
    expect(a + b).toBe(expected);
  });
});
```

## describe.runIf

仅当 `condition` 为真值时运行该 `describe` 块。

```ts
describe.runIf(process.env.RUN_EXTRA === '1')('有条件运行', () => {
  // ...
});
```

## describe.skipIf

当 `condition` 为真值时跳过该 `describe` 块。

```ts
describe.skipIf(process.platform === 'win32')('Windows 下跳过', () => {
  // ...
});
```

## describe.concurrent

并发运行该 `describe` 块内的测试。

```ts
describe.concurrent('并发套件', () => {
  test('test 1', async () => {
    /* ... */
  });
  test('test 2', async () => {
    /* ... */
  });
});
```

## describe.sequential

顺序运行该 `describe` 块内的测试（默认行为）。

```ts
describe.sequential('顺序套件', () => {
  test('test 1', async () => {
    /* ... */
  });
  test('test 2', async () => {
    /* ... */
  });
});
```

## 链式修饰符

`describe` 的修饰符支持按任意顺序链式组合：

- `describe.only.runIf(condition)` / `describe.runIf(condition).only`
- `describe.skipIf(condition).concurrent` / `describe.concurrent.skipIf(condition)`
- `describe.runIf(condition).concurrent` / `describe.concurrent.runIf(condition)`
- `describe.only.concurrent` / `describe.concurrent.only`
- `describe.concurrent.each(cases)` / `describe.each(cases)` 与 `.only`、`.skip`、`.runIf`、`.skipIf` 组合
