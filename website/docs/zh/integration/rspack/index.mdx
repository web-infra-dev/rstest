# Rspack

[Rspack](https://rspack.rs) 是基于 Rust 编写的高性能 JavaScript 打包工具，提供与 webpack 兼容的 API，并支持复用 webpack 的 loader 和插件。

如果你的项目使用 Rspack 构建，可以使用 Rstest 编写和运行测试，并通过适配器复用 Rspack 配置中兼容的编译选项，减少重复配置，让测试编译与项目构建保持一致。

## 快速开始

已有项目可以参考[快速开始](/guide/start/quick-start)，完成 Rstest 的安装和测试脚本配置。

## 复用 Rspack 配置

[@rstest/adapter-rspack](https://www.npmjs.com/package/@rstest/adapter-rspack) 会读取 Rspack 配置，并将兼容的选项转换为 Rstest 测试编译器配置。

### 安装适配器

<PackageManagerTabs command="add @rstest/adapter-rspack -D" />

### 扩展配置

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';
import { withRspackConfig } from '@rstest/adapter-rspack';

export default defineConfig({
  extends: withRspackConfig(),
});
```

适配器会按顺序查找 `rspack.config.{js,ts,mjs,mts,cjs,cts}`（优先 `.js`），将兼容的编译器选项与生成的测试构建合并，并将已加载的配置文件加入 [`forceRerunTriggers`](/config/test/force-rerun-triggers)——当该配置发生变化时，`--changed` 会运行完整测试套件；如果未找到配置文件，则返回 `{}`。同时，适配器会移除 Rsbuild 内置的 CSS 插件（`rsbuild:css`、`rsbuild:less`、`rsbuild:sass`），让你的 Rspack CSS 规则和 loader 直接生效。

:::warning
由于移除了 Rsbuild 内置的 CSS 插件，使用此适配器时，部分 Rsbuild 专属 CSS 选项（例如 `output.cssModules`）不可用，请在 Rspack 配置中处理 CSS。
:::

如果默认的 Rspack 配置与当前项目不匹配，可以通过 `cwd`、`configPath`、`configName`、`env` 或 `nodeEnv` 指定加载方式。如果内存中已有 Rspack 配置对象，可以使用 `toRstestConfig` 直接转换。两种入口、选项详情、映射规则和调试方法请查看[配置参考](./reference)。
