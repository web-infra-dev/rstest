# 浏览器交互

本指南介绍在 Browser Mode 测试中如何模拟用户交互，并帮助你在稳定性、可维护性和控制粒度之间做选择。

在 Browser Mode 下，推荐按以下优先级选择交互方案：

- **Locator API（首选）**：使用 [page.getBy\*](/api/runtime-api/browser-mode/locator#page) + [expect.element](/api/runtime-api/browser-mode/assertion) 做语义化查询、交互和自动重试断言
- **Testing Library**：适合迁移存量用例或复用既有的 [Testing Library](https://testing-library.com/) 工具链
- **原生 DOM API（兜底）**：更轻量，适合需要手动派发事件或精确控制底层事件属性的场景

import { PackageManagerTabs } from '@theme';

## Locator API

Locator API 是 Browser Mode 下的默认选择：`@rstest/browser` 提供 [page](/api/runtime-api/browser-mode/locator#page) 查询和交互入口，`@rstest/core` 提供 [expect.element](/api/runtime-api/browser-mode/assertion) 断言能力。同一套 Playwright 风格的 API 覆盖查询、操作和断言，组件测试与 DOM 测试写法保持一致。

### 示例

```ts
import { page } from '@rstest/browser';
import { expect, test } from '@rstest/core';

test('interacts with form using locator api', async () => {
  document.body.innerHTML = `
    <form aria-label="Login form">
      <label for="username">Username</label>
      <input id="username" />

      <label for="password">Password</label>
      <input id="password" type="password" />

      <label>
        <input id="remember" type="checkbox" />
        Remember me
      </label>

      <button type="button">Login</button>
    </form>
  `;

  await page.getByLabel('Username').fill('alice');
  await page.getByLabel('Password').fill('secret123');
  await page.getByLabel('Remember me').check();
  await page.getByRole('button', { name: 'Login' }).click();

  await expect.element(page.getByLabel('Username')).toHaveValue('alice');
  await expect.element(page.getByLabel('Remember me')).toBeChecked();
});
```

### 常用查询与组合

你可以像 Playwright 一样组合 Locator，把范围逐步收窄到目标元素：

```ts
import { page } from '@rstest/browser';
import { expect, test } from '@rstest/core';

test('composes locators', async () => {
  document.body.innerHTML = `
    <section>
      <h2>Home</h2>
      <button>Save</button>
    </section>
    <section>
      <h2>Profile</h2>
      <button>Save</button>
    </section>
  `;

  const saveInProfileSection = page
    .locator('section')
    .filter({ has: page.getByRole('heading', { name: 'Profile' }) })
    .getByRole('button', { name: 'Save' });

  await expect.element(saveInProfileSection).toHaveCount(1);
});
```

优先使用语义查询（`getByRole`、`getByLabel`），仅在语义信息不足时再使用 `getByTestId` 或 CSS 选择器。Locator API 涵盖语义与属性查询、过滤与 DOM 包装以及集合组合与索引；完整查询方法与严格模式规则（匹配多个元素时需通过 `first()`、`last()` 或 `nth()` 指定具体元素，否则操作会报错）见 [Locator API 文档](/api/runtime-api/browser-mode/locator)。

### 常用交互与断言

可通过 Locator 操作（如 `click`、`fill`、`check`、`hover`、`press`、`selectOption`）、[page.keyboard](/api/runtime-api/browser-mode/keyboard) 和 `page.viewport()` 驱动页面交互，并在关键操作后立即断言可观察结果。Locator 交互会自动等待元素可见、启用且稳定，而 [expect.element](/api/runtime-api/browser-mode/assertion) 断言会自动重试状态、表单、文本、属性与视觉（[toMatchScreenshot()](/api/runtime-api/browser-mode/assertion#toMatchScreenshot)）检查，直到通过或超时。你也可以链式使用 `not` 并传入可选 `timeout`：

```ts
await expect
  .element(page.getByRole('button', { name: 'Save' }))
  .not.toBeDisabled({ timeout: 1000 });
```

完整方法列表见 [Locator API](/api/runtime-api/browser-mode/locator) 和 [浏览器断言 API](/api/runtime-api/browser-mode/assertion)，失败截图配置见 [browser.screenshotFailures](/config/test/browser#screenshotfailures)。

## Testing library

在 Browser Mode 中，[Testing Library](https://testing-library.com/) 更适合用于迁移存量测试或复用既有的查询和交互工具：

- [@testing-library/dom](https://testing-library.com/docs/dom-testing-library/intro)：按用户可感知语义查询元素（如 `getByRole`、`getByText`、`getByLabelText`）
- [@testing-library/user-event](https://testing-library.com/docs/user-event/intro)：模拟完整事件流；编写新的 Browser Mode 测试时仍推荐优先使用 Locator API

### 安装

<PackageManagerTabs command="add @testing-library/dom @testing-library/user-event -D" />

### 示例

```tsx title="src/LoginForm.test.tsx"
import { expect, rs, test } from '@rstest/core';
import { render } from '@rstest/browser-react';
import { getByLabelText, getByRole } from '@testing-library/dom';
import userEvent from '@testing-library/user-event';
import { LoginForm } from './LoginForm';

test('submits login form with user credentials', async () => {
  const user = userEvent.setup();
  const onSubmit = rs.fn();

  const { container } = await render(<LoginForm onSubmit={onSubmit} />);

  // Type into input fields
  await user.type(getByLabelText(container, 'Username'), 'alice');
  await user.type(getByLabelText(container, 'Password'), 'secret123');

  // Check the "remember me" checkbox
  await user.click(getByLabelText(container, 'Remember me'));

  // Submit the form
  await user.click(getByRole(container, 'button', { name: 'Login' }));

  // Assert the form was submitted with correct data
  expect(onSubmit).toHaveBeenCalledWith({
    username: 'alice',
    password: 'secret123',
    rememberMe: true,
  });
});
```

如果项目已经广泛使用 Testing Library，点击、输入、键盘事件、下拉选择和拖拽等其他用法请参考 [user-event 官方文档](https://testing-library.com/docs/user-event/intro)。

## 原生 DOM API

如果不想引入额外依赖，或者需要精确控制底层事件属性（如 `clientX`、`ctrlKey`），可以直接使用浏览器原生 DOM API。

### 示例

```ts title="src/native-events.test.ts"
import { expect, test } from '@rstest/core';

test('handles click and input events', () => {
  // Create elements
  const button = document.createElement('button');
  const input = document.createElement('input');
  document.body.append(button, input);

  // Click event
  let clicked = false;
  button.addEventListener('click', () => (clicked = true));
  button.click();
  expect(clicked).toBe(true);

  // Input event
  input.focus();
  input.value = 'hello';
  input.dispatchEvent(new InputEvent('input', { bubbles: true }));
  expect(input.value).toBe('hello');
});

test('handles keyboard shortcuts', () => {
  let shortcutTriggered = false;

  document.addEventListener('keydown', (e) => {
    // Detect Ctrl+S shortcut
    if (e.ctrlKey && e.key === 's') {
      e.preventDefault();
      shortcutTriggered = true;
    }
  });

  document.dispatchEvent(
    new KeyboardEvent('keydown', {
      key: 's',
      code: 'KeyS',
      ctrlKey: true,
      bubbles: true,
    }),
  );

  expect(shortcutTriggered).toBe(true);
});
```
