# 框架集成

本指南提供各前端框架在浏览器模式下的测试配置示例。

:::tip 前置条件
在继续之前，请确保你已完成浏览器模式的基础配置。你可以通过以下两种方式初始化：

- **自动初始化**：运行 `npx @rstest/core init browser` 命令
- **手动配置**：参考 [快速开始](/guide/browser-testing/getting-started#手动配置) 指南

完成后再按照本页指南进行框架特定的配置。
:::

:::info 框架支持
目前浏览器模式仅对 React 提供开箱即用的支持，其他框架（如 Vue、Svelte 等）将在未来支持。
:::

## React

### 安装依赖

<PackageManagerTabs command="add @rstest/browser-react @rsbuild/plugin-react -D" />

[@rstest/browser-react](https://github.com/web-infra-dev/rstest/tree/main/packages/browser-react) 提供 Browser Mode 下的 React 测试工具：

- `render`：将 React 组件挂载到真实浏览器 DOM 中
- `renderHook`：无需编写包装组件即可测试自定义 Hook
- 自动清理：在每个测试前自动卸载上一个测试渲染的组件

当浏览器测试使用 JSX 时，还需要 [@rsbuild/plugin-react](https://github.com/web-infra-dev/rsbuild/tree/main/packages/plugin-react)（或等价的 React JSX 转换插件），避免运行时出现 `React is not defined` 错误。

### 配置 React JSX 转换

在 Rstest 配置中添加 React JSX 转换插件或等价配置：

```ts title="rstest.config.ts"
import { pluginReact } from '@rsbuild/plugin-react';
import { defineConfig } from '@rstest/core';

export default defineConfig({
  plugins: [pluginReact()],
  browser: {
    enabled: true,
    provider: 'playwright',
  },
});
```

### 组件测试 \{#component-testing}

`render` 将 React 组件挂载到真实浏览器 DOM 中。使用 [Locator API](/guide/browser-testing/user-interactions#locator-api)（`page` + `expect.element`）查询元素、触发交互并断言渲染结果：

```tsx title="src/Counter.test.tsx"
import { page } from '@rstest/browser';
import { render } from '@rstest/browser-react';
import { expect, test } from '@rstest/core';
import { Counter } from './Counter';

test('renders and increments', async () => {
  await render(<Counter />);

  await expect.element(page.getByText('Count: 0')).toBeVisible();

  await page.getByRole('button', { name: 'Increment' }).click();
  await expect.element(page.getByText('Count: 1')).toBeVisible();
});
```

如果组件依赖 Context（如 Theme、Auth、Store），传入 `wrapper` 组件包裹 Provider：

```tsx
const Wrapper = ({ children }: { children: React.ReactNode }) => (
  <ThemeProvider theme="dark">{children}</ThemeProvider>
);

test('renders with theme context', async () => {
  const { container } = await render(<MyComponent />, { wrapper: Wrapper });
  // ...
});
```

#### 对服务端渲染内容进行 hydration \{#hydrating-server-rendered-markup}

<ApiMeta addedVersion="0.12.4" />

组件级 hydration 测试可以在 Browser Mode 中用 `renderToString` 生成匹配的 HTML，再执行 hydration，无需启动 Node 服务。这样能覆盖 React 的 hydration 流程，但不验证 Node 特有的 SSR 行为。若要测试应用实际的服务端输出，则应将该输出放入容器。`onRecoverableError` 等 React root 选项放在 `createRootOptions` 中：

```tsx
import { render } from '@rstest/browser-react';
import { renderToString } from 'react-dom/server';

const container = document.createElement('div');
container.innerHTML = renderToString(<App />);

const recoverableErrors: unknown[] = [];
await render(<App />, {
  container,
  hydrate: true,
  createRootOptions: {
    onRecoverableError: (error) => recoverableErrors.push(error),
  },
});
```

### Hook 测试

`renderHook` 让你无需编写包装组件就能测试自定义 Hook（返回值字段见 [RenderHookResult](/api/runtime-api/browser-mode/react#renderhookresult)）：

```tsx title="src/useCounter.test.tsx"
import { renderHook } from '@rstest/browser-react';
import { expect, test } from '@rstest/core';
import { useCounter } from './useCounter';

test('useCounter increments', async () => {
  const { result, act } = await renderHook(() => useCounter(0));

  expect(result.current.count).toBe(0);

  await act(() => result.current.increment());
  expect(result.current.count).toBe(1);
});
```

如果 Hook 依赖 props，使用 `initialProps` 传入初始值，`rerender` 模拟 props 变化：

```tsx
test('hook reacts to prop changes', async () => {
  const { result, rerender } = await renderHook(
    (props) => useMultiplier(props?.value ?? 0),
    { initialProps: { value: 5 } },
  );

  expect(result.current).toBe(10);

  await rerender({ value: 10 });
  expect(result.current).toBe(20);
});
```

### 更多配置

完整用法请参考 [React API 文档](/api/runtime-api/browser-mode/react)，其中包含 `render`、`renderHook`、`act`、`configure({ reactStrictMode: true })` 以及从 `@rstest/browser-react/pure` 手动调用 `cleanup()` 的参数及返回值。

## Vanilla JS/TS

对于不使用框架的项目，可以直接将 DOM 元素挂载到 `document.body`，配合 [`page` 和 `expect.element`](/guide/browser-testing/user-interactions#locator-api) 测试（DOM 计数器示例见[快速开始](/guide/browser-testing/getting-started#3-编写测试)，Testing Library 和原生 DOM 事件示例见[浏览器交互](/guide/browser-testing/user-interactions)）。

### 测试 Web components

```ts title="src/my-element.test.ts"
import { expect, test } from '@rstest/core';
import './my-element'; // Register custom element

test('renders content in shadow DOM', () => {
  const el = document.createElement('my-element');
  el.setAttribute('name', 'World');
  document.body.appendChild(el);

  const shadowRoot = el.shadowRoot!;
  expect(shadowRoot.textContent).toContain('Hello, World!');
});
```
