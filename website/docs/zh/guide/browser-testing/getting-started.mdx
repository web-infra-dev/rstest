# 快速开始

本指南将帮助你在项目中配置并运行浏览器模式测试。

import { PackageManagerTabs } from '@theme';

## 自动初始化

最快速的方式是使用 `@rstest/core init browser` 命令自动完成配置：

<PackageManagerTabs command="@rstest/core init browser" dlx />

### 初始化过程

运行命令后，Rstest 会自动完成以下工作：

1. **生成样板代码**：Rstest 会自动嗅探项目的框架（React 或原生 DOM）、语言（通过 `tsconfig.json` 判断 TypeScript 或 JavaScript）、测试目录（按 `tests/`、`test/`、`__tests__/`、`src/__tests__/` 顺序检测，默认 `tests/`）和包管理器，并在检测到的测试目录下生成示例组件和测试文件。

2. **创建配置文件**：在项目根目录创建 `rstest.browser.config.mts`，默认启用浏览器模式。

3. **更新 `package.json`**：添加 `test:browser` 脚本（`rstest --config=rstest.browser.config.mts`），并将 `@rstest/browser`、`playwright` 和 `@testing-library/dom`（React 项目还会加入 `@rstest/browser-react`）写入 `devDependencies`。

以下是 React 项目的初始化输出示例：

```bash
Set up Rstest browser mode

  Detecting project...
  ✓ Found React 19.0.0
  ✓ Using playwright as browser provider
  ✓ Test directory: tests/

  Created files:
    - rstest.browser.config.mts
    - tests/Counter.jsx
    - tests/Counter.test.jsx
    - Updated package.json

  Next steps:
    pnpm i
    pnpm dlx playwright install --with-deps
    pnpm run test:browser

└ Done!
```

### 后续步骤

按输出中的提示安装依赖、下载 Playwright 浏览器二进制文件，然后运行浏览器测试。

:::tip 非交互式环境
在 CI 或其他非交互式环境中，添加 `--yes` 参数跳过所有提示，直接使用嗅探到的默认配置：

```bash
npx @rstest/core init browser --yes
```

:::

## 手动配置

### 1. 安装依赖

安装 `@rstest/core`（测试运行器）、`@rstest/browser`（浏览器模式运行时）和 `playwright`（浏览器驱动 peer dependency）：

<PackageManagerTabs command="add @rstest/core @rstest/browser playwright -D" />

下载用于运行测试的 Playwright 浏览器二进制文件：

```bash
npx playwright install chromium
```

也可以安装 Firefox、WebKit 或全部浏览器：

```bash
# 安装 Firefox
npx playwright install firefox

# 安装 WebKit (Safari)
npx playwright install webkit

# 安装所有浏览器
npx playwright install
```

### 2. 创建配置文件

创建或更新 `rstest.config.ts` 配置文件：

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  browser: {
    enabled: true,
    provider: 'playwright',
  },
});
```

### 3. 编写测试

创建一个浏览器测试文件。推荐使用 Locator API 进行元素定位和交互：

```ts title="tests/counter.test.ts"
import { page } from '@rstest/browser';
import { expect, test } from '@rstest/core';

test('counter increments on click', async () => {
  document.body.innerHTML = `
    <button id="count-btn">Count: 0</button>
  `;

  let count = 0;
  document.getElementById('count-btn')!.addEventListener('click', (e) => {
    count++;
    (e.target as HTMLButtonElement).textContent = `Count: ${count}`;
  });

  await expect
    .element(page.getByRole('button', { name: 'Count: 0' }))
    .toBeVisible();
  await page.getByRole('button', { name: 'Count: 0' }).click();
  await expect.element(page.getByText('Count: 1')).toBeVisible();
});
```

这个示例使用 `page.getByRole()` 按语义角色定位按钮，通过 `click()` 触发交互，再用 `expect.element().toBeVisible()` 断言结果。断言会自动等待元素状态变化，无需手写轮询。

## headless vs headed 模式

默认情况下，浏览器模式会根据环境自动选择运行方式：

- **CI 环境**：自动使用 headless 模式（无界面）
- **本地开发**：默认使用 headed 模式（显示浏览器窗口）

### 配置 headless 模式

你可以在配置文件中明确指定：

```ts title="rstest.config.ts"
import { defineConfig } from '@rstest/core';

export default defineConfig({
  browser: {
    enabled: true,
    provider: 'playwright',
    headless: true, // 始终使用无界面模式
  },
});
```
