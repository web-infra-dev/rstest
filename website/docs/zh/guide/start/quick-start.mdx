## 环境准备

开始之前，需要先安装 [Node.js](https://nodejs.org/) 20.x 中的 20.19.0 及以上版本，或 22.12.0 及以上版本（`^20.19.0 || >=22.12.0`）。推荐使用 LTS 版本。

通过以下命令检查当前的 Node.js 版本：

```bash
node -v
```

如果你的环境中尚未安装 Node.js，或是版本太低，可以通过 [nvm](https://github.com/nvm-sh/nvm) 或 [fnm](https://github.com/Schniz/fnm) 安装：

```bash
# 安装 Node.js LTS
nvm install --lts
# 切换 Node.js LTS
nvm use --lts
```

### 手动安装

安装 `@rstest/core` 作为开发依赖：

<PackageManagerTabs command="add @rstest/core -D" />

接着在 `package.json` 中添加 `test` 脚本：

```json title="package.json"
{
  "scripts": {
    "test": "rstest"
  }
}
```

配置好脚本后，可以通过 `npm run test`、`yarn test`、`pnpm test` 或直接使用 `npx rstest` 运行测试。

Rstest 内置了 `watch`、`run`、`list` 等命令，完整命令与选项见 [CLI 工具](/guide/basic/cli)。

## 编写测试

创建源码文件与对应的测试文件（也可以使用类似 [Rust 测试](https://doc.rust-lang.org/book/ch11-03-test-organization.html#the-tests-module-and-cfgtest)的[源码内联测试](/config/test/include-source)）：

```ts title="src/index.ts"
export const sayHi = () => 'hi';
```

```ts title="test/index.test.ts"
import { expect, test } from '@rstest/core';
import { sayHi } from '../src/index';

test('should sayHi correctly', () => {
  expect(sayHi()).toBe('hi');
});
```

运行在[使用 Rstest](#使用-rstest) 中配置的命令，Rstest 会输出如下结果：

```bash
 ✓ test/index.test.ts (1)

 Test Files 1 passed
      Tests 1 passed
   Duration 140 ms (build 17 ms, tests 123 ms)
```

## 类型检查 \{#type-checking}

Rstest 会转换 TypeScript 代码以运行测试，但不会检查类型。测试通过并不代表项目没有类型错误。

请单独运行项目的类型检查。对于已安装 TypeScript 并包含 `tsconfig.json` 的项目，可以添加以下脚本：

```json title="package.json"
{
  "scripts": {
    "test": "rstest",
    "typecheck": "tsc --noEmit"
  }
}
```

在 CI 中同时运行 `test` 和 `typecheck`，分别检查运行时行为和类型。
