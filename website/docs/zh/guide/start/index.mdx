# 介绍

Rstest 是基于 [Rspack](https://rspack.rs/zh) 和 [Rsbuild](https://rsbuild.rs/zh) 的 JavaScript 与 TypeScript 测试框架，提供兼容 Jest 的 API，并原生支持 TypeScript、ESM、CJS 与 CSS Modules。

## ✨ 为什么选择 Rstest

Rstest 基于 Rspack 与 Rsbuild 构建，开箱支持 TypeScript、ESM、CJS 与 CSS Modules，无需迁移现有构建体系即可接入。

对于已经使用 Rstack 工具链（Rspack、Rsbuild、Rslib 等）的项目，Rstest 可以通过适配器复用现有的模块解析、代码转换与插件配置，避免为测试单独维护一套 transform 或 resolver 配置。

在执行模型上，Rstest 采用基于依赖图的 **bundle 模型**运行测试，而不是逐文件转换执行。测试过程可以直接利用 tree-shaking、跳过无副作用 barrel file 中的未用重导出等构建优化，减少大型项目中重复的模块转换与执行开销，也让测试行为更接近生产产物。关于 `sideEffects` 声明如何影响初始化导入，详见[模块副作用](/guide/advanced/side-effects)。

## 🔥 路线图

Rstest 已支持 Node.js 测试、DOM 测试、Browser Mode、Playwright E2E 测试、Mock、多项目工作区与代码覆盖率等核心能力，并在 Rspack、Rsbuild、Rslib 等 Rstack 项目中落地使用。

后续计划请参阅 [Rstest Roadmap](https://github.com/web-infra-dev/rstest/issues/85)。
