# 升级 Rstest

使用 [Taze](https://github.com/antfu-collective/taze) 更新 `package.json` 中的 Rstest 相关依赖。

:::info
Rstest 仍处于 `0.x` 阶段，minor 版本可能包含不兼容变更。跨 minor 版本升级前建议先查看对应的发布说明。
:::

## 使用 Taze

### 使用方法

升级所有包名包含 `rstest` 或 `rsbuild` 的依赖：

```bash
npx taze major --include "/(rstest|rsbuild)/" -w
```

:::tip 为什么需要加 `major`
Rstest 尚未发布 1.0.0，在 SemVer 中 `0.x` 的 minor 升级（如 `0.11` → `0.12`）会被视为破坏性更新。如果不加 `major`，`taze` 默认只会更新同一 minor 范围内的 patch 版本。
:::

输出示例：

```bash
rstest-example - 1 minor

  devDependencies
    @rstest/core    ~14d  ^0.11.0  →  ^0.12.6  ~1d

ℹ changes written to package.json, run pnpm i to install updates.
```

写入完成后，运行包管理器的安装命令（如 `pnpm install` 或 `npm install`）完成依赖安装。

如果只想升级 `@rstest` 命名空间下的包，可以收窄 `include` 匹配模式：

```bash
npx taze major --include "/@rstest/" -w
```

### 选项

- 在 monorepo 中递归升级所有子包（`-r`）：

```bash
npx taze major --include "/(rstest|rsbuild)/" -w -r
```

- 升级锁定的版本号（`-l`）：

```bash
npx taze major --include "/(rstest|rsbuild)/" -w -l
```

更多选项详见 [Taze 文档](https://github.com/antfu-collective/taze)。
